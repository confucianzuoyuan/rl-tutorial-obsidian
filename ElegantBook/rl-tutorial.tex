\section{基本概念}

\textbf{强化学习}（reinforcement learning，RL）讨论的问题是智能体（agent）怎么在复杂、不确定的环境（environment）中最大化它能获得的奖励。

\begin{itemize}
\item Agent：智能体，代理，智能代理
\item Environment：环境
\item State：状态
\item Reward：奖励
\item Action：动作，行动
\end{itemize}

强化学习由两部分组成：\textbf{智能体}和\textbf{环境}。在强化学习过程中，智能体与环境一直在交互。智能体在环境中获取某个状态后，它会利用该状态输出一个动作（action）。然后这个动作会在环境中被执行，环境会根据智能体采取的动作，输出下一个状态以及当前这个动作带来的奖励。智能体的目的就是尽可能多地从环境中获取奖励。

在这个环境中，智能体是推车。

\begin{itemize}
\item 动作空间：推车有两个动作，\textbf{向左推}和\textbf{向右推}
\item 状态：
\begin{itemize}
	\item 推车的位置
	\item 推车的速度
	\item 杆子的角度
	\item 杆子的角速度
\end{itemize}

\item 奖励：推车采取向左推或者向右推的动作之后，只要杆子不倒下，奖励就是1。
\end{itemize}

游戏的结束条件：

\begin{itemize}
\item 推车将杆子推出了屏幕（失败）
\item 杆子倒下（失败）
\item 采取了200次推车的动作，杆子也没倒下（成功）
\end{itemize}

那么推车应该采取什么样的动作，杆子才能不倒下呢？或者说，推车应该采取什么样的\textbf{策略}（policy），杆子才能不倒下呢？因为只有杆子不倒下，我们才能不停的获得奖励。

如果推车每采取一个动作，杆子还能保持平衡，那么我们获得的\textbf{即时奖励}是1。

如果到游戏结束，杆子也没有倒下，那么我们将获得最大的奖励200。

而推车每次要采取什么动作，是取决于环境的状态的。也就是推车要根据环境的状态来决定下一步采取什么动作。例如：此时杆子向左偏，那么推车可能需要采取向左推的动作，才能使杆子不倒下。

换句话说，推车要采取的策略是一个\textbf{函数}。

而这里\textbf{要采取的动作}一般来说是一个概率分布。例如：向左推的概率=0.3，向右推的概率=0.7 。

然后从这个分布中进行采样，采样一个动作出来。当然也可以直接选概率最大的动作。

而我们使用什么样的策略呢？当然是能够让我们在游戏结束时，能够获得最大奖励的策略啦。

当然，这里选择策略有很多的讲究。如果我们每次采取的都是概率最大的动作，那么每次可能都会获得最大的即时奖励。如果这样做的话，可能到了一定的时候，不管向左推还是向右推获得的即时奖励可能都是0，也就是不管怎么推，杆子都会倒下（杆子偏离的角度太大，怎么推都没用）。也就是说，我们太看重眼前利益，忽略了长远的利益。这样就是只\textbf{利用}而不\textbf{探索}。所以有时也需要采取一下概率低的动作，探索一下环境，万一未来获得的奖励更多呢。

所以偶尔也需要采取一下概率小的动作。

\begin{marker}
所谓\textbf{从概率分布中采样}的意思是，例如概率分布是向左推的概率是0.7，向右推的概率是0.3。那么从这个概率分布中采样一个动作出来，有70\%的概率采取的动作是向左推。但也有30\%的概率向右推。
\end{marker}

举个例子：如果我们每次都去最熟悉的餐馆吃饭，可能体验都还可以。而如果去不熟悉的餐厅吃饭，可能体验不好，也可能体验超过了之前的餐馆。在舒适区只利用不探索，就会固步自封。冒险可能会受到伤害，但长期来看，可能会得到提升。

策略是智能体的动作模型，它决定了智能体的动作。它其实是一个函数，用于把输入的状态变成动作。

策略的数学符号是 $\pi$ ，所以策略也就是 $\pi$ 函数。即 $\pi(a | s)=p\left(a_{t}=a | s_{t}=s\right)$ 。输入一个状态 $s$ ，输出一个概率分布。用条件概率来看，就是在条件：状态为 $s$ 的情况下，策略采取动作 $a$ 的概率是多少。这个概率是智能体所有动作的概率，然后对这个概率分布进行采样，可得到智能体将采取的动作。比如可能是有 0.7 的概率往左，0.3 的概率往右，那么通过采样就可以得到智能体将采取的动作。

所以有如下：

\begin{equation}
\begin{aligned}
\pi(a=a_{_\text{向左推}}|s)=0.7 \\
\pi(a=a_{_\text{向右推}}|s)=0.3
\end{aligned}
\end{equation}

如果这个 $\pi$ 函数是一个神经网络，那么这就是\textbf{深度学习 + 强化学习 = 深度强化学习}。当今 AI 界最热门的话题。

所以玩倒立摆游戏的一个\textbf{回合}（episode）就是环境的状态为 $S_0$ ，推车采取动作 $A_0$ ，然后获得奖励 $R_0$ ，然后环境的状态转移到了 $S_1$ ，推车接着采取动作 $A_1$ ，然后获得奖励 $R_1$ ...。下标是时刻，或者时间步。把它们写到一起，就是一个\textbf{轨迹}（trajectory）。轨迹用数学符号 $\tau$ 表示，读作\textbf{掏}。

\begin{equation}
\tau = (S_0,A_0,R_0,S_1,A_1,R_1,S_2,A_2,R_2\dots)
\end{equation}

由于根据环境的状态，采取的动作是从一个概率分布中采样得到的，所以轨迹会有很多很多条。

\section{价值函数（Value Function）}

当位于时刻 $t$ 时，环境此时处于状态 $S_t$ ，然后我们根据策略函数开始采取动作，那么未来我们一共能获得多少奖励呢？环境处于状态 $S_t$ ，我们采取的动作是 $A_t$ ，获取的奖励是 $R_t$ ，然后环境的状态从 $S_t$ 转移到了 $S_{t+1}$ ，然后采取动作 $A_{t+1}$ ，然后获得即时奖励 $R_{t+1}$ ，然后环境的状态从 $S_{t+1}$ 转移到了 $S_{t+2}$ ，然后环境会给我们即时奖励 $R_{t+2}$ ，......。

但是未来的奖励不如现在的奖励有吸引力，所以需要\textbf{打折}。那么，从 $t$ 时刻起，未来一共获得的奖励叫做\textbf{回报}（或者收益，Return）。

\begin{equation}
G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \cdots
\end{equation}

$\gamma$ 叫做折扣因子。随着时间的推移，奖励会被 $\gamma$ 指数级削弱。这个 $\gamma$ 被称为折扣因子（discount rate），其被设定为 $0.0$ 和 $1.0$ 之间的实数。如果折扣因子是 $0.9$，那么有以下式子成立。

\begin{equation}
G_t = R_t + 0.9 R_{t+1} + 0.81 R_{t+2} + \cdots
\end{equation}

引入折现率主要是为了防止连续性任务的收益变得无穷大。在连续性任务中，如果没有折扣因子（或 $\gamma=1$ ），那么收益就会发散到无穷大。因此，设置折扣因子可以防止收益的发散。

折扣因子也使近期的奖励显得更加重要。这解释了人类乃至生物的许多行动原理。例如，你会选择今天拿到 10000 元还是一年后拿到 20000 元？如果折扣因子使未来的回报呈指数级下降，那么眼前的回报就会更有吸引力。

\label{fig:fig-two-timesteps}
\end{figure}

可以看到，一共有 4 条轨迹。每条轨迹都有一个总的回报。而每条轨迹也都有一个产生的概率。那么我们如何评估在环境处于状态 $S_t$ 时，一直采取策略 $\pi$ 未来会获得多少回报呢？也就是未来的预期回报（回报的期望值）是多少呢？那就是\textbf{状态价值函数}（State Value Function）。

\begin{equation}\label{eq:state-value-function-definition}
V_{\pi}(s) = \mathbb{E}_{\pi}\left[G_{t} \mid S_{t}=s\right]=\mathbb{E}_{\pi}\left[\sum_{k=0}^{\infty} \gamma^{k} R_{t+k} \mid S_{t}=s\right], \text{对于所有的} s \in S
\end{equation}

\begin{marker}
状态价值函数，衡量的是在环境处于状态 $s$ 时，一直按照策略 $\pi$ 来采取动作，最终的预期回报。
\end{marker}

状态价值函数的另一种重要的表示形式。

\begin{equation}\label{eq:bellman-expectation-equation}
\begin{aligned}
V_\pi(S_t=s)
&= \mathbb{E}_\pi[R_t+\gamma V_\pi(S_{t+1}=s')|S_t=s] \\
\end{aligned}
\end{equation}

\begin{marker}
贝尔曼期望方程：$V_\pi(S_t) = \mathbb{E}_\pi[R_t+\gamma V_\pi(S_{t+1})|S_t]$
\end{marker}

\begin{marker}
直观解释：
\begin{itemize}
\item 当前环境对你的价值 = 当前环境现在给你的奖励 + 折扣因子 $\times$ 未来环境对你的价值
\item 你对公司的评估 = 现在公司给你的薪资 + 折扣因子 $\times$ 你对公司未来的评估
\end{itemize}
\end{marker}

episode_rewards = []  # 每回合奖励β$[R_0, R_1, \dots, R_T]$β

gamma = 0.95 # 折扣因子β$\gamma$β

# done=True时结束

    # 渲染画面，并保存帧
    frames.append(env.render(mode="rgb_array"))

    # 随机选择一个动作β$A_t$β，0：向左推，1：向右推
    action = random.choice([0, 1])

    # 下一个状态β$S_{t+1}$β，即时奖励β$R_t$β，是否结束，_
    next_state, reward, done, _ = env.step(action)
    # β$[R_0, R_1, \dots, R_T]$β
    episode_rewards.append(reward)

# β逆序计算$G_t = R_t + \gamma G_{t+1}$β
for r in episode_rewards[::-1]:
    total_reward = r + gamma * total_reward

print("total_reward:", total_reward)
env.close()
\end{codebox}

\\

$G_t = R_t + \gamma G_{t+1}$
\\

\end{aligned}
$$
}

前向过程：采样一条轨迹，得到每个时刻的即时奖励。
\\
反向过程：逆序计算回报。
}
}

\section{马尔可夫决策过程}

\subsection{基本概念}

马尔可夫决策过程（MDP，Markov Decision Process）。决策过程是智能体通过与环境互动决定其行动的过程。

智能体所处的环境根据其行动而发生改变。在强化学习中，这种情况被称为环境的``状态''（state）。在MDP中，状态的变化取决于智能体的行动，智能体在环境的状态迁移后执行新的行动。

在MDP中，我们需要``时间''的概念。在某一时刻，智能体会采取行动并因此迁移到一个新的状态。此时的时间单位叫作``时间步''。由于时间步是智能体做出决定的间隔时间，因此它的实际单位取决于问题。

智能体要考虑的是将来获得的奖励总和，而不是眼前的奖励。换句话说，智能体的目标是实现奖励总和最大化。

在MDP中，智能体与环境之间会进行互动。要点在于当智能体采取行动时，状态会发生迁移，随之获得的奖励也会相应改变。

参见图\ref{fig:fig-rl-loop}。

假设在时刻 $t$ 的状态是 $S_t$ 。基于这个状态 $S_t$ ，智能体执行行动 $A_t$ ，获得奖励 $R_t$ 并迁移到下一个状态 $S_{t+1}$ 。智能体与环境之间的这种实际的互动产生了以下迁移。

$$
S_0,A_0,R_0,S_1,A_1,R_1,S_2,A_2,R_2,\cdots
$$

这个时间序列数据从第一个状态 $S_0$ 开始。在状态 $S_0$ ，智能体执行行动 $A_0$ 并获得奖励 $R_0$ 。时刻变为 $1$ ，状态变为 $S_1$ 。接下来，基于状态 $S_1$ ，智能体执行行动 $A_1$ 并获得奖励 $R_1$，然后进入下一个状态 $S_2\cdots\cdots$ 这个流程不断持续下去。

MDP通过数学式来表示智能体、环境以及二者之间的互动。要做到这一点，需要用数学式来表达以下 3 个要素。

\begin{itemize}
\item 状态迁移：状态如何迁移。
\item 奖励：如何给予奖励。
\item 策略：智能体如何决定行动。
\end{itemize}

\subsection{状态转移}

假设智能体现在处于状态 $s$ 并执行了行动 $a$ ，那么转移到下一个状态 $s'$ 的概率可以用如下方式表示。

\begin{equation}
p(s'|s,a)
\end{equation}

\begin{marker}
\begin{itemize}
\item 状态（state）：如果能观察到整个环境完整的信息，就叫做状态
\item 观察（observation）：只能观察到环境的部分状态（信息）
\end{itemize}
\end{marker}

竖杠 $\vert$ 的右侧是表示``条件''的概率变量。对于当前问题，条件对应于在状态 $s$ 选择了行动 $a$ 。在给定这两个条件的情况下，转移到 $s'$ 的概率可以表示为 $p(s'|s,a)$ 。像 $p(s'|s,a)$ 这样的概率叫作状态转移概率（state transition probability）。

给定当前状态$s$和采取的动作$a$的情况下，\textbf{不一定}会确定性的跳转到某个状态$s'$，所以是状态转移概率。

对于倒立摆环境而言，给定当前状态，采取向左推的动作，一定会确定性的跳转到某个状态。

但对于下棋环境来说，棋盘是状态，当Agent下了一个子儿后，棋盘的状态取决于Agent的对手将棋下在哪里，所以状态转移是不确定的。

$p(s'|s,a)$ 决定了下一个状态 $s'$ 只取决于当前状态 $s$ 和行动 $a$ 。

\begin{equation}
p(s_t|s_{t-1},a_{t-1}) = p(s_t|s_{t-1},a_{t-1},s_{t-2},a_{t-2},\dots,s_0,a_0)
\end{equation}

换句话说，状态转移不需要过去的信息——此前处于什么状态以及执行了哪些行动。这个特性被称为\textbf{马尔可夫性质}（Markov property）。

\begin{marker}
MDP通过假设马尔可夫性质的存在来模拟状态转移和奖励。引入马尔可夫性质主要是为了使问题更容易解决。如果不假定马尔可夫性质，那么就必须考虑之前的所有状态和行动，而且组合的数量会呈指数级增长。
\end{marker}

\subsection{奖励函数}

当智能体处于状态 $s$ ，执行行动 $a$，下一个状态是 $s'$ 时，得到的奖励由函数 $r(s,a,s')$ 定义。$r(s,a,s')$ 叫做\textbf{奖励函数}。

\begin{marker}
倒立摆环境中的奖励是确定性的，只要木杆不倒下，就给奖励1。
\end{marker}

奖励函数的建模是一个非常困难的问题，例如：我们的机器人Agent，它的任务是将插头正确的插入插座，如果只有正确的插入插头才会给奖励1，其它情况都给奖励0，那么机器人可能一辈子也拿不到奖励了。这叫做\textbf{奖励稀疏性问题}。

\subsection{策略}

策略表示智能体如何决定其行动。策略的关键在于它使得智能体仅根据当前状态来决定其行动。之所以说只基于当前状态就足够了，是因为环境的迁移是符合马尔可夫性质的。

环境的状态迁移只以当前状态 $s$ 和行动 $a$ 为条件来决定下一个状态 $s'$ ，而不需要先前的信息。同样，奖励也是基于当前状态 $s$ 、行动 $a$ 和迁移后的状态 $s'$ 来决定的。这意味着关于环境的所有必要信息都在当前状态中。因此，智能体只需基于当前状态即可决定其行动。

\begin{marker}
MDP的马尔可夫性质可以被看作是对环境而不是对智能体的约束。这意味着为了满足马尔可夫性质，环境需要保持某个``状态''。从智能体的角度来看，在当前状态下有足够的信息来做出最佳选择，所以它可以在此基础上采取行动。
\end{marker}

智能体的行动是由随机性策略决定的，数学式如\ref{eq:random-policy}所示。

\begin{equation}\label{eq:random-policy}
\pi(a|s)
\end{equation}

$\pi(a|s)$ 表示在状态 $s$ 下采取行动 $a$ 的概率。

我们已经成功地用数学式来表示状态迁移、奖励函数和策略。接下来让我们使用这三者来定义MDP的目标。

\subsection{MDP的目标}

到目前为止，我们已经用数学式描述了环境和智能体的行动。简要回顾一下，智能体根据策略 $\pi(a|s)$ 采取行动。首先，它根据它的行动和状态迁移概率 $p(s'|s,a)$ 迁移到下一个状态。然后，它根据奖励函数 $r(s,a,s')$ 获得奖励。在这个框架内，MDP的目标是找到\textbf{最优策略}（optimal policy）。最优策略是使收益最大化的策略。

\subsection{收益}

为了定义收益，我们思考这样一个场景：设时刻为 $t$ ，状态为 $S_t$ （其中 $t$ 是任意值）。然后，智能体根据策略 $\pi$ 执行行动 $A_t$ ，获得奖励 $R_t$ ，之后迁移到新状态 $S_{t+1}$，这个过程不断重复进行。在这种情况下，收益 $G_t$ 的定义如\ref{eq:timestep-t-return}所示。

\begin{equation}\label{eq:timestep-t-return}
G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \cdots
\end{equation}

$\gamma$ 为折扣因子。

\subsection{状态价值函数}

我们已经重新定义了``收益''。智能体的目标是使这种收益最大化。这里有一点需要注意，那就是智能体和环境的行动可能是``随机性''的。智能体可能随机地决定行动，状态也可能随机迁移。在这种情况下，获得的收益将呈现随机的特点。即使从相同的状态开始，不同回合的收益也随机变化。例如，某个回合的收益为 $10.4$ ，另一个回合的收益为 $8.7$ 。

为了处理这种随机行动，需要使用期望值或``收益的期望值''作为衡量标准。收益的期望值的数学式如\ref{eq:gt-expectation}所示。

\begin{equation}\label{eq:gt-expectation}
v_\pi(s) = \mathbb{E}[G_t|S_t=s,\pi]
\end{equation}

我们指定的条件是状态 $S_t$ 为 $s$ 智能体的策略为 $\pi$ （其中时刻 $t$ 是任意值）。在这些条件下，智能体获得的收益的期望值为上面的公式。在这里，我们用特殊符号 $v_\pi(s)$ 来表示收益的期望值。就是\textbf{状态价值函数}（state-value function）。

在公式的右侧，智能体的策略 $\pi$ 被作为条件给出。这是因为如果策略 $\pi$ 发生变化，那么智能体获得的奖励也会发生变化，而这些奖励的总和，即收益也会发生变化。为了明确这一点，状态价值函数通常会写作 $v_\pi(s)$ ，将 $\pi$ 写在 $v$ 的右下角。此外，上面的公式也可以写成下面的形式。

\begin{equation}
v_\pi(s) = \mathbb{E}_\pi[G_t|S_t=s]
\end{equation}

在上面的式子中，记载 $\pi$ 的位置是 $\mathbb{E}_\pi$ 。与式（1）一样，这么写的含义是策略 $\pi$ 是作为条件给出的。从现在起，本教程将采取式（2）的风格来书写式子。

在强化学习中，我们的目标是获得最优策略。

最优策略的状态价值函数叫作\textbf{最优状态价值函数}（optimal state-value function）。可以使用 $v_*$ 来表示最优状态价值函数。

\section{贝尔曼方程}

贝尔曼方程是在MDP中成立的最重要的方程，为许多强化学习算法提供了重要基础。

这里使用骰子作为例子。我们使用的骰子是理想的六面体，每一面的数字出现的概率都是 $\frac{1}{6}$ 。在数学式中，我们用随机变量 $x$ 表示掷骰子出现的数字， $x$ 是 $1$ 和 $6$ 之间的整数。那么每个数字出现的概率就是 $\frac{1}{6}$ 。 我们用 $p(x)=\frac{1}{6}$ 表示骰子的数字出现的概率。现在来计算掷骰子的期望值。计算式如下所示。

\begin{equation}
\begin{aligned}
\mathbb{E}[x] &= 1\times\frac{1}{6}+2\times\frac{1}{6}+3\times\frac{1}{6}+4\times\frac{1}{6}+5\times\frac{1}{6}+6\times\frac{1}{6} \\
&= 3.5
\end{aligned}
\end{equation}

如上所述，期望值是在所有情况下``出现的数字''和``概率''相乘并加在一起得到的和。顺带一提，如果使用 $\sum$ 符号，那么期望值的数学式如下所示。

\begin{definition}{期望的定义}{}
\begin{equation}
\begin{aligned}
\mathbb{E}[x] &= \sum_xxp(x) \\
\mathbb{E}[f(x)] &= \sum_xf(x)p(x)
\end{aligned}
\end{equation}
\end{definition}

\begin{marker}
\begin{itemize}
\item 全期望公式：$\mathbb{E}[X]=\mathbb{E}[\mathbb{E}[X|Y]]$
\item 条件期望的迭代公式：$\mathbb{E}[X|Y]=\mathbb{E}[\mathbb{E}[X|Z]|Y]$
\end{itemize}
\end{marker}

另外，$x$和$y$同时发生的概率（这叫作``联合概率''）如\ref{eq:union-probability}所示。

\begin{equation}\label{eq:union-probability}
p(x,y)=p(x)p(y|x)=p(y)p(x|y)
\end{equation}

假设奖励用 $r(x,y)$ 来表示，那么奖励的期望值如下

\begin{equation}
\begin{aligned}
\mathbb{E}[r(x,y)] &= \sum_x\sum_yp(x,y)r(x,y) \\
&= \sum_x\sum_yp(x)p(y|x)r(x,y)
\end{aligned}
\end{equation}

回顾收益（回报）的定义。

\begin{equation}
G_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \cdots
\end{equation}

那么有以下公式

\begin{equation}
G_{t+1} = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots
\end{equation}

所以有以下递推公式：

\begin{equation}
\begin{aligned}
G_t &= R_t+\gamma R_{t+1}+\gamma^2R_{t+2}+\cdots \\
&= R_t + \gamma(R_{t+1}+\gamma R_{t+2}+\cdots) \\
&= R_t+\gamma G_{t+1}
\end{aligned}
\end{equation}

这种递推关系被用于强化学习的许多理论和算法中。

下面将递推公式代入状态价值函数的定义式中。状态价值函数是收益的期望值，其数学式的定义如下所示。

\begin{equation}
v_\pi(s) = \mathbb{E}_\pi[G_t|S_t=s]
\end{equation}

如上面的公式所示，状态 $s$ 的价值函数被表示为 $v_\pi(s)$ 。将递推公式带入上面的式子的 $G_t$ 中，得到下面的式子：

\begin{equation}
\begin{aligned}
v_\pi(s) &= \mathbb{E}_\pi[G_t|S_t=s] \\
&= \mathbb{E}_\pi[R_t+\gamma G_{t+1}|S_t=s] \\
&= \mathbb{E}_\pi[R_t|S_t=s] + \gamma\mathbb{E}_\pi[G_{t+1}|S_t=s]
\end{aligned}
\end{equation}

\begin{marker}
期望的线性性质：$\mathbb{E}[X+Y] = \mathbb{E}[X] + \mathbb{E}[Y]$
\end{marker}

先来推导上面公式中的第一项 $\mathbb{E}_\pi[R_t|S_t=s]$ 。

$\mathbb{E}_\pi[R_t|S_t=s]$ 的含义是在 $t$ 时刻，环境的状态是 $s$ ，那么在 $t$ 时刻，获得的即时奖励的期望是多少呢？那么需要考虑所有的情况，然后加起来就可以了。

\begin{equation}\label{eq:bellman-first-term}
\mathbb{E}_\pi[R_t|S_t=s]=\sum_a\sum_{s'}\pi(a|s)p(s'|s,a)r(s,a,s')
\end{equation}

如上面的数学式\ref{eq:bellman-first-term}所示，将智能体行动的概率 $\pi(a|s)$ 、要迁移的状态的概率 $p(s'|s,a)$ 和奖励函数 $r(s,a,s')$ 相乘。对所有候选项都进行上述计算，得到它们的总和。

\begin{marker}
式\ref{eq:bellman-first-term}中只有$s$是确定的，假设可选动作只有两个$\left\{ a_1, a_2 \right\}$，环境状态只有两种$\left\{ s_1, s_2 \right\}$。那么状态转移和概率如下：
\begin{equation*}
\begin{aligned}
s \rightarrow a_1 \rightarrow s_1: \pi(a=a_1|s) = 0.2, p(s'=s_1|s,a=a_1) = 0.3, r(s,a=a_1,s'=s_1)=10 \\
s \rightarrow a_1 \rightarrow s_2: \pi(a=a_1|s) = 0.2, p(s'=s_2|s,a=a_1) = 0.7, r(s,a=a_1,s'=s_2)=20 \\
s \rightarrow a_2 \rightarrow s_1: \pi(a=a_2|s) = 0.8, p(s'=s_1|s,a=a_2) = 0.5, r(s,a=a_2,s'=s_1)=30 \\
s \rightarrow a_2 \rightarrow s_2: \pi(a=a_2|s) = 0.8, p(s'=s_2|s,a=a_2) = 0.5, r(s,a=a_2,s'=s_2)=40 \\
\end{aligned}
\end{equation*}
那么即时奖励的期望是：
\begin{equation*}
\begin{aligned}
E &= 0.2\times 0.3\times 10 + 0.2\times 0.7\times 20 + 0.8\times 0.5\times 30 + 0.8\times 0.5\times 40 \\
&= 0.6 + 2.8 + 12.0 + 16.0 \\
&= 31.4
\end{aligned}
\end{equation*}
\end{marker}

第一项推导完毕，接下来推导第二项。

\end{equation*}

剩下的项是 $\gamma\mathbb{E}_\pi[G_{t+1}|S_t=s]$ 。由于 $\gamma$ 是常数，因此我们要看的是 $\mathbb{E}_\pi[G_{t+1}|S_t=s]$ 。这个式子虽然与状态价值函数的定义式相似，但在 $G_{t+1}$ 的部分有所不同。状态价值函数的式子如下所示，式子中是 $G_t$ ，而不是 $G_{t+1}$ 。

\begin{equation}
v_\pi(s) = \mathbb{E}_\pi[G_t|S_t=s]
\end{equation}

因此，我们首先要将 $t+1$ 代入上面的式子的 $t$ 中。式子变化如下。

\begin{equation}
v_\pi(s) = \mathbb{E}_\pi[G_{t+1}|S_{t+1}=s]
\end{equation}

这就是状态 $S_{t+1}=s$ 时的价值函数。接下来要关注的是 $\mathbb{E}_\pi[G_{t+1}|S_t=s]$ 。这是在当前时刻为 $t$ 时，下一个时刻 $(t+1)$ 的收益期望值。解决的关键在于将条件 $S_t=s$ 变为 $S_{t+1}=s$ 的形式。换句话说，就是要进入下一个时刻。

通过观察可以得到

\begin{equation}
\begin{aligned}
\mathbb{E}_\pi[G_{t+1}|S_t=s] &= \sum_{a,s'}\pi(a|s)p(s'|s,a)\mathbb{E}_\pi[G_{t+1}|S_{t+1}=s'] \\
&= \sum_{a,s'}\pi(a|s)p(s'|s,a)v_\pi(s')
\end{aligned}
\end{equation}

完成第二项的展开以后，汇总一下得到

\begin{theorem}{贝尔曼方程}{}
\begin{equation}\label{eq:bellman-equation}
\begin{aligned}
v_\pi(s) &= \mathbb{E}_\pi[R_t|S_t=s] + \gamma\mathbb{E}_\pi[G_{t+1}|S_t=s] \\
&= \sum_{a,s'}\pi(a|s)p(s'|s,a)r(s,a,s')+\gamma\sum_{a,s'}\pi(a|s)p(s'|s,a)v_\pi(s') \\
&= \sum_{a,s'}\pi(a|s)p(s'|s,a)\{r(s,a,s')+\gamma v_\pi(s')\}
\end{aligned}
\end{equation}
\end{theorem}

上面的式子\ref{eq:bellman-equation}就是大名鼎鼎的\textbf{贝尔曼方程}。贝尔曼方程是表示状态 $s$ 的价值函数和下一个可能的状态 $s'$ 的价值函数之间关系的式子。这个贝尔曼方程对所有状态 $s$ 和所有策略 $\pi$ 都成立。

状态价值函数的贝尔曼方程的另一种重要的表示形式：\textbf{贝尔曼期望方程}。

\begin{theorem}{贝尔曼期望方程}{}
\begin{equation}\label{eq:bellman-expectation-equation-0}
\begin{aligned}
V_\pi(S_t)
&= \mathbb{E}_\pi[R_t+\gamma V_\pi(S_{t+1})|S_t] \\
\end{aligned}
\end{equation}
\end{theorem}

贝尔曼期望方程的推导过程如下：

\begin{equation}
\begin{aligned}
V_\pi(S_t) &= \mathbb{E}_\pi[G_t|S_t] \\
&= \mathbb{E}_\pi\left[\sum_{k=0}^\infty\gamma^kR_{t+k}\mid S_t\right] \\
&= \mathbb{E}_\pi\left[R_t+\gamma\sum_{k=0}^\infty\gamma^kR_{t+k+1}\mid S_t\right] \\
&= \mathbb{E}_\pi[R_t+\gamma G_{t+1}|S_t] \\
&= \mathbb{E}_\pi[R_t|S_t]+\gamma \mathbb{E}_\pi[G_{t+1}|S_t] \\
&= \mathbb{E}_\pi[R_t|S_t]+\gamma \mathbb{E}_\pi[\mathbb{E}_\pi [G_{t+1}|S_{t+1}]|S_t] \\
&= \mathbb{E}_\pi[R_t|S_t]+\gamma \mathbb{E}_\pi[V_\pi(S_{t+1})|S_t] \\
&= \mathbb{E}_\pi[R_t+\gamma V_\pi(S_{t+1})|S_t] \\
\end{aligned}
\end{equation}

还是倒立摆环境，每当倒立摆环境处于某个状态 $s$ 时，我们就会使用神经网络 $\pi_\theta$ 来决定要采取什么动作。

那么，问题是：这个神经网络怎么训练？

\begin{marker}
想要训练一个神经网络，需要有\textbf{输入-输出}对。例如，mnist手写数字数据集，要训练一个可以识别手写数字的卷积神经网络，需要构建一个网络结构，然后提供输入（图片）以及输出（分类标签）。

当然，还得有\textbf{损失函数}，例如交叉熵损失函数或者均方误差损失函数，等等。
\end{marker}

但是对于倒立摆环境，想要训练推车的策略神经网络，输入是什么，输出是什么？以及损失函数又是什么？

首先回顾一下第一章的知识。

首先明确问题的设定。这里考虑的是回合制任务，并基于策略 $\pi_{\theta}$ 选择动作的情况。在这种情况下，假定得到了以下由``状态、动作、奖励''构成的时间序列数据。

\begin{equation}
\tau = (S_0, A_0, R_0, S_1, A_1, R_1, \cdots, S_{T+1})
\end{equation}

这个 $\tau$ 也叫作轨迹（trajectory）。

而一条轨迹发生的概率是：

\begin{equation}
\begin{aligned}
\Pr(\tau)
&=p\left(S_{0}\right) \pi_{\theta}\left(A_{0} | S_{0}\right) p\left(S_{1} | S_{0}, A_{0}\right) \pi_{\theta}\left(A_{1} | S_{1}\right) p\left(S_{2} | S_{1}, A_{1}\right) \cdots \pi_{\theta}\left(A_{T} | S_{T}\right) p\left(S_{T+1} | S_{T}, A_{T}\right) \\
&=p\left(S_{0}\right) \prod_{t=1}^{T} \pi_{\theta}\left(A_{t} | S_{t}\right) p\left(S_{t+1} | S_{t}, A_{t}\right)
\end{aligned}
\end{equation}

此时可以使用折扣因子 $\gamma$ 对回报（Return，收益）作如下定义。

\begin{equation}
G(\tau) = R_0 + \gamma R_1 + \gamma^2 R_2 + \cdots + \gamma^T R_T
\end{equation}

为了表明回报可以由 $\tau$ 计算出来，上面的式子将其表示为了 $G(\tau)$ 。此时，目标函数 $J(\theta)$ 可以表示为式\ref{eq:rl-objective}。

\begin{definition}{强化学习的目标函数}{}
\begin{equation}\label{eq:rl-objective}
J(\theta) = \mathbb{E}_{\tau\sim\pi_{\theta}}[G(\tau)]
\end{equation}
\end{definition}

回报 $G(\tau)$ 是随机变动的，所以它的期望值是目标函数。上式中期望值 $E$ 的下标为 $\tau\sim\pi_{\theta}$ ，这个下标表示 $\tau$ 是基于 $\pi_{\theta}$ 生成的。

\begin{marker}
我们的目标是让 $J(\theta) = \mathbb{E}_{\tau\sim\pi_{\theta}}[G(\tau)]$ 最大。但是我们发现$G(\tau)$这个轨迹的回报无法求导，换句话说就是对目标函数\textbf{无法进行优化}。
\end{marker}

\begin{marker}
目标函数可以优化的意思其实就是可以求导。
\end{marker}

在神经网络的训练中，我们的目的是让\textbf{损失函数}最小。而在策略梯度法中，我们的目的是让\textbf{目标函数}最大。所以都可以使用梯度法。让损失函数最小，使用梯度下降法。让目标函数最大，使用梯度上升法。

所以，我们还是得求解 $J(\theta)$ 的梯度。需要求导的参数是 $\theta$ 。

确定了目标函数后，下一步是计算它的梯度。这里将参数 $\theta$ 的梯度表示为 $\nabla_{\theta}$ 。我们的目标是求 $\nabla_{\theta}J(\theta)$ 。$\nabla$ 是梯度符号。

\begin{theorem}{策略梯度定理}{}
\begin{equation}\label{eq:policy-gradient-formula}
\begin{aligned}
\nabla_{\theta}J(\theta) &= \nabla_{\theta}\mathbb{E}_{\tau\sim\pi_{\theta}}[G(\tau)] \\
&= \mathbb{E}_{\tau\sim\pi_{\theta}}[\sum_{t=0}^TG(\tau)\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)]
\end{aligned}
\end{equation}
\end{theorem}

公式\ref{eq:policy-gradient-formula}非常的重要。需要仔细研究。

\begin{marker}
梯度上升算法：$\theta \leftarrow \theta + \alpha\nabla_{\theta}J(\theta)$
\end{marker}

上面的式子朝着梯度的方向更新参数 $\theta$ 。更新的值与 $\alpha$ 相关。这里的 $\alpha$ 表示学习率。这是属于梯度上升法的算法。

只要沿着梯度上升的方向更新参数 $\theta$ ，那么目标函数 $J(\theta)$ 就会越来越大，也就是所有轨迹的期望就会越来越大，那么就是我们的策略越来越好了。

\begin{marker}
策略梯度法求得的梯度是一个期望值，而期望值无法计算。
\end{marker}

这里有一个问题，那就是真正的期望是无法准确求出来的。因为期望是所有的轨迹得到的奖励计算出来的。而轨迹有无数条。如果我们能够走满倒立摆的 200 步，那么不同轨迹的数量可能是 $2^{200}$，如图\ref{fig:unlimited-samples}，这是一个天文数字。所以我们希望能够求出\textbf{近似}期望值的数值。比如利用\textbf{大数定理}，多采样几条轨迹，那么就会比较接近期望值。

$$
\frac{1+2+3+4+5+6}{6}=3.5
$$
根据大数定理，如果多次抛掷骰子，随着抛掷次数的增加，平均值（样本平均值）应该接近3.5。
\\
如果随机变量$X_1,X_2,\ldots$是独立同分布，且期望$\mathbb{E}(X_1)=\mathbb{E}(X_2)=\cdots=\mu$。那么
$$
\bar{X}_n=\frac{1}{n}(X_1+X_2+\cdots+X_n)
$$
当$n\rightarrow{\infty}$时, 收敛于真值
$$
\bar{X}_n\rightarrow\mu

如式所示，$\nabla_{\theta}J(\theta)$ 表示期望值。接下来我们来计算期望值。这里，我们令策略 $\pi_{\theta}$ 的智能体实际采取动作，得到 $n$ 个轨迹 $\tau$ ，如图\ref{fig:n-samples}。此时，通过对每个 $\tau$ 计算式子的期望值内部的式子（$\sum_{t=0}^TG(\tau)\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)$），并求出其平均值，从而近似得到 $\nabla_{\theta}J(\theta)$ 。数学式如\ref{eq:sample-n-cal-expectation}所示。

\begin{equation}\label{eq:sample-n-cal-expectation}
\begin{aligned}
\text{采样}: \tau^{(i)}\sim\pi_{\theta}\;\;\;\;(i=1,2,\cdots,n) \\
x^{(i)} = \sum_{t=0}^TG(\tau^{(i)})\nabla_{\theta}\log\pi_{\theta}(A_t^{(i)}|S_t^{(i)}) \\
\nabla_{\theta}J(\theta) \approx \frac{x^{(1)}+x^{(2)}+\cdots+x^{(n)}}{n}
\end{aligned}
\end{equation}

上面式子中的 $\tau^{(i)}$ ，表示在第 $i$ 回合得到的轨迹，$A_t^{(i)}$ 表示在第 $i$ 回合的时刻 $t$ 的动作，$S_t^{(i)}$ 表示在第 $i$ 回合的时刻 $t$ 的状态。

\subsection{代码实现}

接下来，我们用代码来实现一下策略梯度法。

我们讲一些实现细节。我们可以把强化学习想成一个分类问题，这个分类问题就是输入倒立摆的状态，输出某个类。在解决分类问题时，我们要收集一些训练数据，数据中要有输入与输出的对。在实现的时候，我们把倒立摆的状态当作分类器的输入，就像在解决图像分类的问题，只是现在的类不是图像里面的东西，而是看到倒立摆的状态我们要采取什么样的动作，每一个动作就是一个类。比如第一个类是向左，第二个类是向右。

在解决分类问题时，我们要有输入和正确的输出，要有训练数据。但在强化学习中，我们通过采样来获得训练数据。假设在采样的过程中，在某个状态下，我们采样到要采取动作 $A$， 那么就把动作 $A$ 当作标准答案（ground truth）。比如，我们在某个状态下，采样到要向左。因为是采样，所以向左这个动作不一定概率最高。假设我们采样到向左，在训练的时候，让智能体调整网络的参数，如果看到某个状态，我们就向左。在一般的分类问题里面，我们在实现分类的时候，目标函数都会写成最小化交叉熵（cross entropy），最小化交叉熵就是最大化对数似然（log likelihood）。

\mybox[blue]{从极大似然估计的角度看策略梯度}{
\begin{equation*}
\begin{aligned}
J(\theta) &= \sum_{t=0}^TG(\tau)\log \pi_{\theta}(A_{t}|S_{t}) \\
&= G(\tau)\log{\left(\prod_{t=0}^T\pi_{\theta}(A_{t}|S_{t})\right)}
\end{aligned}
\end{equation*}
最大化目标就会提升某些状态对应的动作的概率。
}

\begin{codebox}{python}{策略神经网络$\pi_\theta$}
class PolicyNet(nn.Module):
    def __init__(self, action_size):
        super().__init__()
        self.l1 = nn.Linear(4, 128) # 推车环境中状态是一个4维数组
        self.l2 = nn.Linear(128, action_size) # 输出是一个2维数组

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = F.softmax(self.l2(x), dim=1)
        return x # 输出：β$[\pi_\theta(a=\text{向左推}|s),\pi_\theta(a=\text{向右推}|s)]$β
\end{codebox}

这里实现的神经网络模型由两层全连接层构成。最终输出的元素数是动作的数量（\py{action_size}）。由于这个最终输出是\py{softmax}函数的输出，因此可以得到每个动作的概率。

这个网络结构就是我们要训练的策略神经网络 $\pi_\theta$ 。其中 $\theta$ 就是神经网络的参数。

我们还记得，策略神经网络的输入是环境的状态，输出是要采取的动作的概率分布。所谓动作的概率分布就是：向左推的概率是多少，向右推的概率是多少。

而我们的网络结构输入的张量的维度是 4 。为什么呢？因为倒立摆环境的状态有 4 个维度。

输出是\py{action_size}个维度。也就是动作的数量个维度。

\mybox[blue]{softmax函数}{
如果将具有 $n$ 个元素的向量输入到softmax函数中，那么输出的同样是具有 $n$ 个元素的向量。此时，第 $i$ 个输出 $y_i$ 的式子如下所示。
\begin{equation*}
y_i = \frac{\mathrm{e}^{x_i}}{\sum_{k=1}^n\mathrm{e}^{x_k}}
\end{equation*}
这里的 $\mathrm{e}$ 是自然常数(值为 $2.718 28...$ 的无限小数)。softmax函数的输出值全部为 $0$ 以上 $1$ 以下的实数，它们的合计值为 $1$（$\sum_{i=1}^ny_i=1$）。因此，softmax函数的输出可以作为概率使用。
}

下面是 \py{Agent} 类的代码。首先显示初始化和 \py{get_action} 方法。

\begin{codebox}{python}{智能体代码}
class Agent:
    def __init__(self):
        self.gamma = 0.98 # β折扣因子$\gamma$β
        self.lr = 0.0002 # β学习率$\alpha$β
        self.action_size = 2 # 两个动作

        self.pi = PolicyNet(self.action_size) # β策略神经网络$\pi_\theta$β
        self.optimizer = optim.Adam(self.pi.parameters(), lr=self.lr)

    def get_action(self, state):
        # β$(4,)\rightarrow(1,4)$β
        state = torch.tensor(state[np.newaxis, :])
        # probs: [[向左推的概率, 向右推的概率]]
        probs = self.pi(state)
        # 取出概率分布：[向左推的概率, 向右推的概率]
        probs = probs[0]
        # 根据动作的概率分布创建一个二项分布
        m = Categorical(probs)
        # 使用二项分布采样动作β$\pi_\theta(a_t|s_t)$β
        action = m.sample().item()

        # (采样的动作, [向左推的概率, 向右推的概率])
        return action, probs
\end{codebox}

\py{get_action} 方法决定了在 \py{state} 状态下采取的动作。为此，可以通过 \py{self.pi(state)} 进行神经网络的前向传播，得到概率分布 \py{probs} 。然后，基于该概率分布，进行一次动作的采样。该方法还返回了所有动作的概率（上面代码中的\py{probs}）。

下面来试用一下 \py{get_action} 方法。代码如下所示。

\begin{codebox}{python}{}
env = gym.make("CartPole-v0")
state = env.reset() # β$S_0$β
agent = Agent()

action, probs = agent.get_action(state)
print("动作：", action) # β$A_0$β
print("动作的概率：", probs[action].item()) # β$\pi_\theta(A_0|S_0)$β

G = 100.0 # β$G(\tau)$β
J = -G * probs[action].log() # β$-G(\tau)\log{\pi_\theta(A_0|S_0)}$β
print('J: ', J)

J.backward() # 求导（梯度）β$-\nabla_\theta G(\tau)\log{\pi_\theta(A_0|S_0)}$β
agent.optimizer.step() # 梯度下降：β$\theta=\theta+\alpha\nabla_\theta G(\tau)\log{\pi_\theta(A_0|S_0)}$β
# 在相同的状态state下，采取动作的概率变大了
# （测试一下）将G变为负值，也就是负的奖励，会发现采取动作的概率下降了
_, probs = agent.get_action(state)
print("动作：", action)
print("动作的概率：", probs[action].item())
\end{codebox}

上面的代码取出了初始状态下的动作及其概率。另外，它还显示了使用虚拟的权重来计算由式\ref{eq:first-step-backward}表示的梯度的代码（这是从式子\ref{eq:first-step-backward}取出的 $t = 0$ 的相关项的式子）。

\begin{equation}\label{eq:first-step-backward}
G(\tau)\nabla_{\theta}\log\pi_{\theta}(A_0|S_0)
\end{equation}

作为参考，下面对照列出了上面的代码中出现的变量与相应的数学式。

\begin{itemize}
\item \py{probs[action]}：$\pi_{\theta}(A_0|S_0)$
\item \py{G}：$G(\tau)$
\item \py{J}：$G(\tau)\log\pi_{\theta}(A_0|S_0)$
\end{itemize}

求出\py{J}之后，通过\py{J.backward()}求 $G(\tau)\nabla_{\theta}\log\pi_{\theta}(A_0|S_0)$ 。下面是\py{Agent}类剩下的代码。

\begin{codebox}{python}{采集轨迹的代码和更新策略的代码}
class Agent:
    ...

    def collect_trajectory(self, env):
        state = env.reset()
        states, actions, rewards = [], [], []
        done = False

        while not done:
            action, _ = self.get_action(state)
            next_state, reward, done, _ = env.step(action)
            states.append(state) # β$S_t$β
            actions.append(action) # β$A_t$β
            rewards.append(reward) # β$R_t$β
            state = next_state # β$S_t \rightarrow S_{t+1}$β
        # β$[S_0, S_1, \dots, S_T]$β
        # β$[A_0, A_1, \dots, A_T]$β
        # β$[R_0, R_1, \dots, R_T]$β
        return states, actions, rewards

    def update(self, trajectory):
        states, actions, rewards = trajectory
        # 逆序计算β$G(\tau)$β
        G = 0
        for r in rewards[::-1]:
            G = r + self.gamma * G
        loss = 0
        for s, a in zip(states, actions):
            _, probs = self.get_action(s)
            log_prob = torch.log(probs)[a] # β$\log\pi_\theta(A_t|S_t)$β
            loss += -log_prob * G # β$-\sum_{t=0}^{T}G(\tau)\log\pi_\theta(A_t|S_t)$β

        self.optimizer.zero_grad()
        loss.backward() # β$\nabla_\theta\left\{ -\sum_{t=0}^{T}G(\tau)\log\pi_\theta(A_t|S_t) \right\}$β
        self.optimizer.step() # β$\theta=\theta-\alpha\nabla_\theta\left\{ -\sum_{t=0}^{T}G(\tau)\log\pi_\theta(A_t|S_t) \right\}$β
\end{codebox}

在训练神经网络时，通常要设置损失函数。对于这个例子，我们可以将目标函数 $J(\theta)$ 乘以 $-1$ 所得到的 $-J(\theta)$ 作为损失函数，此时可以通过梯度下降法的最优化方法（SGD、Adam等）更新参数。

\subsection{深入讨论}

采样一条轨迹的梯度是 $\nabla_{\theta}J(\theta) \approx \sum_{t=0}^TG(\tau)\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)$。

如果将梯度符号去掉，可以得到如下：

\begin{equation}
\begin{aligned}
J(\theta) & \approx \sum_{t=0}^TG(\tau)\log\pi_{\theta}(A_t|S_t) \\
& = G(\tau)\sum_{t=0}^T\log\pi_{\theta}(A_t|S_t) \\
& = G(\tau)\left( \log\pi_\theta(A_0|S_0) + \log\pi_\theta(A_1|S_1) + \dots\right)
\end{aligned}
\end{equation}

我们的目标是让 $J(\theta)$ 越大越好，那么在经过梯度上升算法之后，$J(\theta)$会变大，那么肯定有的 $\log\pi_\theta(A_t|S_t)$ 变大了，也可能有的 $\log\pi_\theta(A_{t'}|S_{t'})$ 变小了，但总和肯定变大了。也就是说，策略梯度法的本质是，我们使用\textbf{当前策略}$\pi_\theta$采样一条轨迹$\tau$，如果采样的轨迹的回报$G(\tau)$很高，那么说明我们在某个状态$S_t$采取的动作$A_t$比较好，导致了总的奖励也就是回报比较高。那么通过梯度上升法，更新$\theta$之后，新的策略$\pi_{\theta_\text{new}}$会提升\textbf{在 $S_t$ 时执行 $A_t$ 的概率}。例如 $A_t$ 是``向左推车''，那么在 $S_t$ 状态下策略采取``向左推车''的概率就会提升，而同时策略采取``向右推车''的概率就会下降。

举一个最简单的例子，我们采样的轨迹只执行了一步动作，就结束了。那么有如下公式

\begin{equation}
J(\theta) = G(\tau)\log\pi_\theta(A_0|S_0)
\end{equation}

\begin{itemize}
\item 如果$G>0$，那么对 $J(\theta)$ 优化之后，策略 $\pi_\theta$ 在状态 $S_0$ 时采取动作 $A_0$ 的概率一定会变大。
\item 如果$G<0$，那么对 $J(\theta)$ 优化之后，策略 $\pi_\theta$ 在状态 $S_0$ 时采取动作 $A_0$ 的概率一定会变小。
\end{itemize}

如果$G$特别大，例如$G=10000$，或者$G$特别小，例如$G=-10000$，那么梯度上升算法的步长$\alpha G\nabla_\theta\log_{\pi_{\theta}}(A_0|S_0)$的绝对值一定会很大，进而导致策略的参数$\theta$更新幅度巨大，进而导致策略$\pi_\theta$爆炸式的更新。

换句话说，我们只是提高了在状态$S_0=s$是采取动作$A_0$的概率，但是在玩倒立摆游戏时，并不能保证状态$s$经常出现。碰到其它的状态，更新后的策略表现可能非常的差。好比一个人，突然间中了1000万，那么如此大的奖励会直接彻底改变这个人的策略，他的策略彻底变成了靠运气生活。或者一个人犯了一点点小错误，却得到了巨大的惩罚，如此大的惩罚也会让一个人信心崩溃。这就是策略崩溃的例子。

\section{REINFORCE}

\subsection{REINFORCE算法}

REINFORCE是对上一节的策略梯度法的改进算法。本节首先会基于数学式推导REINFORCE算法，然后会通过修改之前的部分代码的做法来实现REINFORCE。

\begin{marker}
REINFORCE这个名字是``REward Increment = Nonnegative Factor $\times$ Offset Reinforcement $\times$ Characteristic Eligibility''（奖励增量=非负因子$\times$偏移强化$\times$特征资格）的首字母缩写。
\end{marker}

先来复习一下第一节。最简单的梯度策略法是基于下面的公式实现的。

\begin{equation}
\begin{aligned}
\nabla_{\theta}J(\theta) &= \nabla_{\theta}E_{\tau\sim\pi_{\theta}}[G(\tau)] \\
&= E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^TG(\tau)\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)]
\end{aligned}
\end{equation}

上面的式子中的 $G(\tau)$ 是目前为止获得的所有奖励的总和（准确地说是``带折扣因子''的奖励的总和）。这里要思考的问题是，无论在哪个时刻 $t$ ，式子中都是 $G(\tau)\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)$ ，我们始终会使用固定不变的权重 $G(\tau)$ 来增加（或减少）采取行动 $A_t$ 的概率。

智能体行动的好坏是根据行动之后获得的奖励总和来评估的（回顾一下价值函数的定义）。反过来说，采取某个行动之前获得的奖励与该行动的好坏无关。如果要评估在某个时刻 $t$ 采取的行动 $A_t$ ，那么在此之前做了什么以及获得了多少奖励都无所谓。我们是根据采取行动 $A_t$ 之后的结果（在时刻 $t$ 以后获得的奖励的总和）来判断行动 $A_t$ 的好坏的。

上面的式子中行动 $A_t$ 的权重是 $G(\tau)$ 。这个权重 $G(\tau)$ 包括在时刻 $t$ 之前的奖励。也就是说，原本不相关的奖励作为噪声数据包含在内了。为了改进这一点（去除噪声数据），可以对权重 $G(\tau)$ 作如下修改。

\begin{theorem}{REINFORCE版策略梯度定理}{}
\begin{equation}\label{eq:reinforce-pg-theorem}
\begin{aligned}
\nabla_{\theta}J(\theta) &= E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^TG_t\nabla_{\pi}\log\pi_{\theta}(A_t|S_t)] \\
G_t &= R_t + \gamma R_{t+1} + \cdots + \gamma^{T-1}R_T
\end{aligned}
\end{equation}
\end{theorem}

如式\ref{eq:reinforce-pg-theorem}所示，权重变成了 $G_t$ 。权重 $G_t$ 是在时刻 $t\sim T$ 获得的奖励的总和。因此，选择行动 $A_t$ 的概率将由不包含时刻 $t$ 之前的奖励的权重 $G_t$ 增强。 这就是改进第一节的策略梯度法的思路。基于式\ref{eq:reinforce-pg-theorem}的算法叫作\textbf{REINFORCE}。

\begin{marker}
基于上式的REINFORCE算法优于最简单的策略梯度法（基于第一节的公式的算法）。通过无限增加的样本数，两个公式都会收敛到正确的 $\nabla_{\theta}J(\theta)$ （可以说是无偏差的）。但第一个公式的方差更大，因为公式中的权重包含了无关的数据（噪声）。
\end{marker}

\subsection{REINFORCE的代码实现}

由于REINFORCE的方差小，因此即使数据样本少，也能高精度地近似数据。下面我们来实现REINFORCE以验证其精度。REINFORCE的代码与上一节中的代码基本相同，不同之处只有 \py{Agent} 类的 \py{update} 方法。下面仅列出了不同部分的代码。

\begin{codebox}{python}{}
class Agent:
    ...

    def update(self, trajectory):
        states, actions, reward_list = trajectory
        G, loss = 0, 0
        for r, s, a in zip(reward_list[::-1], states[::-1], actions[::-1]):
            G = r + self.gamma * G
            _, probs = self.get_action(s)
            log_prob = torch.log(probs)[a]
            loss += -log_prob * G

        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
\end{codebox}

\py{self.memory} 是按先后顺序保存智能体获得的奖励（\py{reward}）和行动概率（\py{prob}）的列表。上面的代码按从后向前的顺序依次访问了 \py{self.memory} 的元素，并计算了每个时刻的 \py{G} 。

\section{基线（baseline）}

\begin{marker}
前面介绍的REINFORCE玩倒立摆有一个问题，那就是不管我们怎么推车，获得的奖励都是正奖励。也就是说不管怎么玩，我们都会提升某个状态采取某个动作的概率，即使奖励很少也是如此。其实我们在玩倒立摆时，获得的奖励很少时，应该降低某个状态下采取某个动作的概率。也就是说，我们应该在获得的奖励很多时，给予策略正的奖励，而在获得奖励很少时，给予策略负的奖励。这样会更加的合理。这就是\textbf{基线}的技术。

倒立摆环境中只要倒立摆没有倒，给出的奖励总是 1 。也就是不管策略多么的差劲，采样出的轨迹的回报一定是正的。也就是说，即使轨迹的回报很低，也会提升在 $S_t$ 采取 $A_t$ 的概率，只是可能提升的不大。

如果加入基线，那么如果轨迹的回报很低，权重就会成为负值，从而在策略更新之后，直接降低在 $S_t$ 采取 $A_t$ 的概率。所以训练速度会加快。
\end{marker}

下面介绍一种叫作基线（baseline）的技术，该技术可以改进REINFORCE。让我们先通过一个简单的例子来了解一下基线的思路，然后再将基线应用于REINFORCE。

\subsection{带基线的策略梯度法}

式\ref{eq:reinforce-baseline-1}是REINFORCE的数学式。将基线应用于这个REINFORCE的数学式如式\ref{eq:reinforce-baseline-2}所示。

\begin{theorem}{带基线的REINFORCE策略梯度定理}{}
\begin{align}
\nabla_{\theta}J(\theta) &= E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^T G_t\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)] \label{eq:reinforce-baseline-1} \\
&= E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^T (G_t-b(S_t))\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)] \label{eq:reinforce-baseline-2}
\end{align}
\end{theorem}

式\ref{eq:reinforce-baseline-2}用 $G_t-b(S_t)$ 代替了 $G_t$ 。这里 $b(S_t)$ 可以是任何函数。也就是说，只要输入是 $S_t$ ， $b(S_t)$ 是什么函数都行。这个 $b(S_t)$ 就是基线（baseline）。

式\ref{eq:reinforce-baseline-2}中的 $b(S_t)$ 可以是任何函数。例如，在状态 $S_t$ 下，可以考虑使用之前获得的奖励的平均值作为 $b(S_t)$ 。实践中经常使用的是价值函数，数学式为 $b(S_t)=V_{\pi_{\theta}}(S_t)$ 。如果能够使用基线减小方差，那么就可以进行样本效率更高的训练。另外，将价值函数作为基线使用时，我们是不知道真正的价值函数 $v_{\pi_{\theta}}(S_t)$ 的。这种情况下还需要训练价值函数神经网络。

最后，我们再通过直观介绍补充说明一下为什么使用基线更好。这里以倒立摆为例，思考图\ref{fig:cartpole-failed}的状态。

\subsection{Actor-Critic的数学推导}

首先从复习带基线的REINFORCE开始。带基线的REINFORCE的目标函数的梯度的数学式如\ref{eq:pg-with-baseline}所示。

\begin{equation}\label{eq:pg-with-baseline}
\nabla_{\theta}J(\theta)=E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^T(G_t-b(S_t))\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)]
\end{equation}

式\ref{eq:pg-with-baseline}中的 $G_t$ 表示回报，$b(S_t)$ 表示基线。可以使用任何函数作为基线。这里我们使用基于神经网络建模的价值函数作为基线。因此，我们要用到以下这些新的记号。

\begin{itemize}
\item $\omega$ ：表示价值函数的神经网络的所有权重参数。
\item $V_{\omega}(S_t)$ ：将价值函数模型化的神经网络。
\end{itemize}

此时目标函数的梯度的数学式如式\ref{eq:actor-critic-objective}所示

\begin{theorem}{Actor-Critic架构的REINFORCE策略梯度定理}{}
\begin{equation}\label{eq:actor-critic-objective}
\nabla_{\theta}J(\theta)=E_{\tau\sim\pi_{\theta}}\left[\sum_{t=0}^T(G_t-V_{\omega}(S_t))\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)\right]
\end{equation}
\end{theorem}

式\ref{eq:actor-critic-objective}中存在一个问题，即只要没抵达目标，就无法确定回报 $G_t$ 的值。也就是说，在抵达目标之前，无法更新策略和价值函数。如果这是基于蒙特卡洛方法的算法，那么二者无法更新就是它的缺点。

\begin{marker}
我们之前使用的是\textbf{蒙特卡洛采样}，也就是采样出一条完整的轨迹。然后更新策略神经网络$\pi_\theta$。
\end{marker}

消除这个缺点的方法是\textbf{时序-差分方法}（TD方法，Time Difference Method）。使用TD方法训练价值函数时，使用1个时间步（或 $n$ 个时间步）后的结果就能进行更新，如图所示。

如图所示，在训练价值函数 $V_{\omega}(S_t)$ 时，蒙特卡洛方法使用的是回报 $G_t$ ，而TD方法使用的是 $R_t+\gamma V_{\omega}(S_{t+1})$ 。

\mybox[blue]{时序差分误差}{
使用神经网络对价值函数建模时，我们以接近 $R_t+\gamma V_{\omega}(S_{t+1})$ 为目标训练 $V_{\omega}(S_t)$ 的值。具体来说就是将 $V_{\omega}(S_t)$ 和 $R_t+\gamma V_{\omega}(S_{t+1})$ 的均方差作为损失函数，通过梯度下降法更新神经网络的权重。
\newline
贝尔曼期望方程：$V_\omega(S_t)=\mathbb{E}_\pi\left[ R_t + \gamma V_\omega(S_{t+1}) | S_t \right]$
\newline
可以看到$V_{\omega}(S_t)\leftarrow{R_t+\gamma V_{\omega}(S_{t+1})}$是由贝尔曼期望方程而来的。
}

下面将基于蒙特卡洛方法的公式切换为TD方法，其中，代替 $G_t$ 的是 $R_t+\gamma V_{\omega}(S_{t+1})$ 。此时得到的式子如下所示。

\begin{theorem}{1步TD误差的Actor-Critic策略梯度定理}{}
\begin{equation}\label{eq:one-td-step-pg}
\nabla_{\theta}J(\theta)=E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^T(R_t+\gamma V_{\omega}(S_{t+1})-V_{\omega}(S_t))\nabla_{\theta}\log\pi_{\theta}(A_t|S_t)]
\end{equation}
\end{theorem}

1步TD误差经常表示为 $\delta = R_{t} + \gamma V_{\omega}(S_{t+1}) - V_{\omega}(S_{t})$

基于上面的公式\ref{eq:one-td-step-pg}的算法就是 Actor-Critic 。策略 $\pi_{\theta}$ 和价值函数 $V_{\omega}$ 是神经网络，我们要同时训练这两个神经网络。具体来说，对于策略 $\pi_{\theta}$ 要基于上面的公式进行训练；而对于价值函数 $V_{\omega}$ ，则通过 TD 方法，以接近 $R_t+\gamma V_{\omega}(S_{t+1})$ 为目标训练 $V_{\omega}(S_t)$ 这个神经网络。

\begin{marker}
Actor-Critic 中的 Actor 是\textbf{演员}（采取动作的人）的意思，也就是采取动作的人，相当于策略 $\pi_{\theta}$ 。而 Critic 是\textbf{评论家}的意思，相当于价值函数 $V_{\omega}$ 。因此，Actor-Critic 的意思是``使用 $V_{\omega}$ ，来评论基于策略 $\pi_{\theta}$ 采取的动作的好坏''。
\end{marker}

\subsection{Actic-Critic的代码实现}

下面实现Actor-Critic。策略和价值函数这两个神经网络的代码如下所示。

\begin{codebox}{python}{策略网络和价值网络}
class PolicyNet(nn.Module):
    def __init__(self, action_size):
        super().__init__()
        self.l1 = nn.Linear(4, 128)
        self.l2 = nn.Linear(128, action_size)

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = F.softmax(self.l2(x), dim=1)
        return x

class ValueNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.l1 = nn.Linear(4, 128)
        self.l2 = nn.Linear(128, 1)

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = self.l2(x)
        return x
\end{codebox}

上面的代码将策略的网络实现为了 \py{PolicyNet} 类，将价值函数的网络实现为了 \py{ValueNet} 类。策略的最终输出是 \py{Softmax} 函数的输出，所以输出的是概率。接下来是 \py{Agent} 类的代码。

\begin{codebox}{python}{Agent代码}
class Agent:
    def __init__(self):
        self.gamma = 0.98 # 折扣因子β$\gamma$β
        self.lr_pi = 0.0002 # 策略网络的学习率β$\alpha_\text{actor}$β
        self.lr_v = 0.0005 # 价值网络的学习率β$\alpha_\text{critic}$β
        self.action_size = 2
        # 初始化策略网络（演员网络）β$\pi_\theta$β
        self.pi = PolicyNet(self.action_size)
        # 初始化价值函数网络（评论家网络）β$V_\omega$β
        self.v = ValueNet()

        self.optimizer_pi = optim.Adam(self.pi.parameters(), lr=self.lr_pi)
        self.optimizer_v = optim.Adam(self.v.parameters(), lr=self.lr_v)

    def get_action(self, state):
        state = torch.tensor(state[np.newaxis, :])
        probs = self.pi(state)
        probs = probs[0]
        m = Categorical(probs)
        action = m.sample().item()
        return action, probs

    def update(
        self,
        state, # β$S_t$β
        action_prob, # β$\pi_\theta(A_t|S_t)$β
        reward, # β$R_t$β
        next_state, # β$S_{t+1}$β
        done
    ):
        state = torch.tensor(state[np.newaxis, :]) # β$S_t$β
        next_state = torch.tensor(next_state[np.newaxis, :]) # β$S_{t+1}$β

        # β$\circled{1}$βself.v 的损失：均方差
        # β$\text{TD目标}=R_t+\gamma{V_\omega(S_{t+1})}$β
        target = reward + self.gamma * self.v(next_state) * (1 - done)
        # 从计算图中剥离，不参与反向传播
        target.detach()
        v = self.v(state) # β$V_\omega(S_t)$β
        loss_fn = nn.MSELoss() # β$(R_t+\gamma{V_\omega(S_{t+1})}-V_\omega(S_t))^2\rightarrow{0}$β
        loss_v = loss_fn(v, target)

        # β$\circled{2}$βself.pi 的损失
        delta = target - v # β$\delta=R_t+\gamma{V_\omega(S_{t+1})}-V_\omega(S_t)$β
        loss_pi = -torch.log(action_prob) * delta.item() # β$-\left( R_t+\gamma{V_\omega(S_{t+1})}-V_\omega(S_t) \right)\log{\pi_\theta(A_t|S_t)}$β

        self.optimizer_v.zero_grad()
        self.optimizer_pi.zero_grad()
        loss_v.backward() # β$\nabla_\omega(R_t+\gamma{V_\omega(S_{t+1})}-V_\omega(S_t))^2$β
        loss_pi.backward() # β$-\left( R_t+\gamma{V_\omega(S_{t+1})}-V_\omega(S_t) \right)\nabla_\theta\log{\pi_\theta(A_t|S_t)}$β
        self.optimizer_v.step()
        self.optimizer_pi.step()
\end{codebox}

\py{get_action} 方法可以基于策略取出动作。需要注意的是，由于输入到神经网络中的数据将作为小批量进行处理，因此在处理其中一个数据（状态）时需要小批量的轴。另外，\py{get_action} 方法返回了两个值，即选择的动作及其概率。选择动作的概率将在稍后的损失函数计算中使用。

\py{update}方法可以训练价值函数和策略。在代码 $\circled{1}$ 处为价值函数(\py{self.v})计算损失。为此要计算TD目标（target），求出当前状态下其与价值函数（v）的均方差。然后，在代码 $\circled{2}$ 处为策略（\py{self.pi}）计算损失。需要将其乘以 $-1$ 的值作为损失。剩下的就是一直以来的神经网络的训练代码。

\begin{codebox}{python}{Actor-Critic智能体的训练代码}

agent = Agent()

episode_list = []

for episode in range(2000):
    state = env.reset()
    done = False
    total_reward = 0

    while not done:
        action, probs = agent.get_action(state)
        next_state, reward, done, info = env.step(action)
        # 执行完一个动作，立即更新 β$\pi_\theta$β 和 β$V_\omega$β 这两个网络
        agent.update(state, probs[action], reward, next_state, done)

        state = next_state
        total_reward += reward

    return_list.append(total_reward)
    episode_list.append(episode)
    if episode % 100 == 0:
        print("回合:{}, 总奖励:{:.1f}".format(episode, total_reward))

\section{广义优势估计}

\begin{marker}
广义优势估计：Generalized Advantage Estimation，GAE
\end{marker}

上面的1步TD误差表示为：$\delta = R_{t} + \gamma V_{\omega}(S_{t+1}) - V_{\omega}(S_{t})$。在很多强化学习文献中，这个叫做优势$A$（Advantage）。

也就是1步TD目标$R_{t} + \gamma V_{\omega}(S_{t+1})$相对于基线$V_{\omega}(S_{t})$的优势是多少。

我们在上一节的Actor-Critic中使用1步TD误差来作为优势。而现在常用的一种方法是针对\textbf{多步TD误差}计算指数加权平均的方式来估算优势，也就是\textbf{广义优势估计}。

首先，$t$时刻的1步TD误差是：

$$
\delta_t=R_t+\gamma V(s_{t+1})-V(s_t)
$$

其中$V$是价值函数神经网络$V_\omega$。那么我们计算一下多步TD误差：

$$
\begin{aligned}
A_t^{(1)} &= \delta_t &&= -V(s_t)+R_t+\gamma V(s_{t+1}) \\
A_t^{(2)} &= \delta_t+\gamma\delta_{t+1} &&= -V(s_t)+R_t+\gamma R_{t+1}+\gamma^2 V(s_{t+2}) \\
A_t^{(3)} &= \delta_t+\gamma\delta_{t+1}+\gamma^2 \delta_{t+2} &&= -V(s_t)+R_t+\gamma R_{t+1}+ \gamma^2R_{t+2} +\gamma^3 V(s_{t+3}) \\
&\quad\vdots &&\quad\quad\vdots \\
A_t^{(k)} &= \sum_{l=0}^{k-1}\gamma^l\delta_{t+l} &&= -V(s_t)+R_t+\gamma R_{t+1}+\cdots+\gamma^{k-1}R_{t+k-1}+\gamma^kV(s_{t+k})
\end{aligned}
$$

然后，GAE将这些不同步数的优势估计进行指数加权平均：

$$
\begin{aligned}
A_t^{\text{GAE}} &= (1-\lambda)(A_t^{(1)}+\lambda A_t^{(2)}+\lambda^2A_t^{(3)}+\cdots) \\
&= (1-\lambda)(\delta_t+\lambda(\delta_t+\gamma\delta_{t+1})+\lambda^2(\delta_t+\gamma\delta_{t+1}+\gamma^2\delta_{t+2})+\cdots) \\
&= (1-\lambda)(\delta_t(1+\lambda+\lambda^2+\cdots)+\gamma\delta_{t+1}(\lambda+\lambda^2+\lambda^3+\cdots)+\gamma^2\delta_{t+2}(\lambda^2+\lambda^3+\lambda^4+\cdots)+\cdots) \\
&= (1-\lambda)\left({\delta_t\frac{1}{1-\lambda}+\gamma\delta_{t+1}\frac{\lambda}{1-\lambda}+\gamma^2\delta_{t+2}\frac{\lambda^2}{1-\lambda}+\cdots}\right) \\
&= \sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}
\end{aligned}
$$

其中，$\lambda\in [0,1]$ 是在GAE中额外引入的一个超参数。当 $\lambda=0$ 时，$A_t^{\text{GAE}}=\delta_t=R_t+\gamma V(s_{t+1})-V(s_t)$ ，也就是仅仅只看一步差分得到的优势；当 $\lambda=1$ 时，$A_t^{\text{GAE}}=\sum_{l=0}^{\infty}\gamma^l\delta_{t+l}=\sum_{l=0}^{\infty}\gamma^lR_{t+l}-V(s_t)$ ，则是看每一步差分得到的优势的完全平均值。

有上面的式子，我们还可以推导出一个递推公式

$$
A_t = \delta_t + \gamma\lambda A_{t+1}
$$

下面是计算GAE的代码，给定 $\gamma$ 和 $\lambda$ 以及每个时间步的 $\delta_t$ 之后，我们可以根据公式直接进行优势估计。

先前向（forward）计算每一个时刻的\textbf{1步TD误差}，然后再逆向（backward）计算每一个时刻的GAE。

首先，我们有 $n$ 个1步TD误差。

$$
\text{TD}_\delta = \left[\delta_t, \delta_{t+1}, \dots, \delta_{t+n}\right]
$$

先把数组逆序

$$
\text{TD}_\delta = \left[\delta_{t+n}, \delta_{t+n-1}, \dots, \delta_{t}\right]
$$

然后遍历逆序数组，有如下结果：

$$
\begin{aligned}
A_{t+n} &= \delta_{t+n} \\
A_{t+n-1} &= \delta_{t+n-1} + \gamma\lambda A_{t+n} \\
A_{t+n-2} &= \delta_{t+n-2} + \gamma\lambda A_{t+n-1} \\
\vdots \\
A_t &= \delta_t + \gamma\lambda A_{t+1}
\end{aligned}
$$

这样每一个时间步的广义优势估计就计算出来了。

\begin{theorem}{GAE的Actor-Critic策略梯度定理}{}
\begin{equation}\label{eq:gae-pg}
\nabla_{\theta}J(\theta)=E_{\tau\sim\pi_{\theta}}[\sum_{t=0}^TA^{\text{GAE}}_t\nabla_{\theta}\log\pi_{\theta}(a_t|s_t)]
\end{equation}
\end{theorem}

\begin{marker}
为了使符号更清晰，将动作$A_t$改为$a_t$，将状态$S_t$改为$s_t$。$A^{\text{GAE}}_t$中的$A$表示``Advantage''（优势）。
\end{marker}

\section{相关证明}

\subsection{策略梯度法的证明}

当 $J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{G(\tau)}\right\rbrack$ 时，其梯度如下面的式子所示。

$$
\nabla_\theta{J(\theta)}=\mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{\sum_{t=0}^TG(\tau)\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack
$$

下面对上面的式子进行证明。

$$
\begin{aligned}
\nabla_\theta{J(\theta)} &= \nabla_\theta\mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{G(\tau)}\right\rbrack \\
&= \nabla_\theta\sum_\tau{\Pr(\tau|\theta)G(\tau)} \quad{\color{cyan}\text{（展开期望值）}} \\
&= \sum_\tau\nabla_\theta(\Pr(\tau|\theta)G(\tau)) \quad{\color{cyan}\text{（将}\nabla_\theta\text{移动到}\sum\text{中）}} \\
&= \sum_\tau\left\lbrace{G(\tau)\nabla_\theta\Pr(\tau|\theta)+\Pr(\tau|\theta)\nabla_\theta{G(\tau)}}\right\rbrace \quad{\color{cyan}\text{（积的微分）}} \\
&= \sum_\tau{G(\tau)\nabla_\theta\Pr(\tau|\theta)} \quad{\color{cyan}\text{（}\nabla_\theta{G(\tau)}\text{永远为0）}} \\
&= \sum_\tau G(\tau)\Pr(\tau|\theta){\color{red}\frac{\nabla_\theta\Pr(\tau|\theta)}{\Pr(\tau|\theta)} \quad{\color{cyan}\text{（乘以}{\frac{\Pr(\tau|\theta)}{\Pr(\tau|\theta)}}\text{）}}} \\
&= \sum_\tau G(\tau)\Pr(\tau|\theta){\color{red}\nabla_\theta\log\Pr(\tau|\theta)} \quad{\color{cyan}\text{（}\log\text{梯度的技巧）}} \\
&= \mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{G(\tau)\nabla_\theta\log\Pr(\tau|\theta)}\right\rbrack
\end{aligned}
$$

这里对``log梯度的技巧''进行说明。这个技巧利用了以下等式。

$$
\nabla_\theta\log\Pr(\tau|\theta)=\frac{\nabla_\theta\Pr(\tau|\theta)}{\Pr(\tau|\theta)}
$$


\begin{marker}
log梯度技巧：$\log(f(x))'=\frac{f'(x)}{f(x)}$
\end{marker}

根据上面的式子，我们就知道

\begin{equation}
\nabla_\theta\Pr(\tau|\theta)=\Pr(\tau|\theta)\nabla_\theta\log\Pr(\tau|\theta)
\end{equation}

这就是著名的\textbf{log梯度的技巧}。是机器学习领域常用的数学式的变形形式。

接下来，我们将利用以下等式进一步展开$(1)$。

\begin{equation}
\begin{aligned}
\Pr(\tau|\theta) &= p(S_0)\pi_\theta(A_0|S_0)p(S_1|S_0,A_0)\cdots\pi_\theta(A_T|S_T)p(S_{T+1}|S_T,A_T) \\
&= p(S_0)\prod_{t=0}^T\pi_\theta(A_t|S_t)p(S_{t+1}|S_t,A_t)
\end{aligned}
\end{equation}

这里，$p(S_0)$ 表示初始状态 $S_0$ 的概率。上面的式子表明，得到轨迹 $\tau$ 的概率可以用初始状态的概率、策略以及下一个状态的迁移概率的乘积来表示。另外，我们可以用下面的式子来表示 $\log\Pr(\tau|\theta)$ 。

\begin{equation}
\log\Pr(\tau|\theta)=\log{p(S_0)} + \sum_{t=0}^T\log{p(S_{t+1}|S_t,A_t)} + \sum_{t=0}^T\log\pi_\theta(A_t|S_t)
\end{equation}

由于 $\log xy = \log x + \log y$ ，所以可以像上面的式子那样表示为和的形式。基于上面的式子，可以将 $\nabla_\theta{\log\Pr(\tau|\theta)}$ 展开为如下形式。

\begin{equation}
\begin{aligned}
\nabla_\theta\log\Pr(\tau|\theta) &= \nabla_\theta\left\lbrace\log{p(S_0)} + \sum_{t=0}^T\log{p(S_{t+1}|S_t,A_t)} + \sum_{t=0}^T\log\pi_\theta(A_t|S_t)\right\rbrace \\
&= \nabla_\theta\sum_{t=0}^T\log\pi_\theta(A_t|S_t)
\end{aligned}
\end{equation}

$\nabla_\theta$ 是对 $\theta$ 的梯度。与 $\theta$ 无关的元素的梯度 $\nabla_\theta\log p(S_0)$ 和 $\nabla_\theta\sum_{t=0}^T\log{p(S_{t+1}|S_t,A_t)}$ 为 0 。因此，从上面的式子可以得到下列式子。

\begin{equation}
\begin{aligned}
\nabla_\theta{J(\theta)}&=\mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{G(\tau)\nabla_\theta\log\Pr(\tau|\theta)}\right\rbrack \\
&= \mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{\sum_{t=0}^TG(\tau)\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack
\end{aligned}
\end{equation}

这样我们就完成了 $\nabla_\theta{J(\theta)}$ 的推导。

\mybox[blue]{从极大似然估计的角度看策略梯度}{
$$
\begin{aligned}
J(\theta) &= \sum_{t=0}^TG(\tau)\log \pi_{\theta}(A_{t}|S_{t}) \\
&= G(\tau)\log{\left(\prod_{t=0}^T\pi_{\theta}(A_{t}|S_{t})\right)}
\end{aligned}
$$
最大化目标就会提升某些状态对应的动作的概率。
}

\subsection{基线的推导}

$$
\begin{aligned}
\nabla_\theta J(\theta) &= \mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{\sum_{t=0}^TG_t\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack \\
&= \mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{\sum_{t=0}^T(G_t-b(S_t))\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack \\
&= \mathbb{E}_{\tau\sim \pi_{\theta}}\left[ \sum_{t=0}^TG_{t}\nabla_{\theta}\log \pi_{\theta}(A_{t}|S_{t})\right] -\mathbb{E}_{\tau\sim \pi_{\theta}}\left[ \sum_{t=0}^Tb(S_{t})\nabla_{\theta}\log \pi_{\theta}(A_{t}|S_{t}) \right] \\
&= \mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{\sum_{t=0}^TG_t\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack \\
\end{aligned}
$$

如上面的式子所示，我们可以使用 $G_t-b(S_t)$ 代替 $G_t$ 。$b(S_t)$ 是\textbf{任何函数}，我们称之为``基线''。下面进行上式的推导。

首先，证明以下式子成立。

$$
\mathbb{E}_{x\sim P_\theta}\left\lbrack{\nabla_\theta\log P_\theta(x)}\right\rbrack = 0
$$

这里假设随机变量 $x$ 是基于概率分布 $P_\theta(x)$ 生成的。$P_\theta(x)$ 会根据参数 $\theta$ 改变概率分布的形状。此时有以下式子成立。

$$
\sum_xP_\theta(x)=1
$$

由于 $P_\theta(x)$ 是概率分布，因此所有 $x$ 的值的和为 1 。然后，求这个式子的梯度。

$$
\nabla_\theta\sum_xP_\theta(x)=\nabla_\theta 1 = 0
$$

接下来，使用log梯度的技巧将式子展开，过程如下所示。

$$
\begin{aligned}
0 &= \nabla_\theta\sum_xP_\theta(x) \\
&= \sum_x\nabla_\theta P_\theta(x) \\
&= \sum_xP_\theta(x)\nabla_\theta\log P_\theta(x) \\
&= \mathbb{E}_{x\sim P_\theta}\left\lbrack{\nabla_\theta\log P_\theta(x)}\right\rbrack
\end{aligned}
$$

证明(1)完毕。接下来将证明的式子用于我们的问题。具体来说，用 $A_t$ 代替(1)中的 $x$ ，然后使用 $\pi_\theta(\cdot|S_t)$ 代替 $P_\theta(\cdot)$ 。这样就可以得到以下式子。

$$
\mathbb{E}_{A_t\sim\pi_\theta}\left\lbrack{\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack = 0
$$

上面的式子是对 $A_t$ 的期望值。因此，我们可以像下面的式子那样，将任何函数 $b(S_t)$ 放入期望值中。$E[x]=0\to E[cx]=c\cdot 0=0$ 。

$$
\mathbb{E}_{A_t\sim\pi_\theta}\left\lbrack{b(S_t)\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack = 0
$$

$b(S_t)$ 是以 $S_t$ 为参数的函数，即使 $A_t$ 发生变化，它的值也不会改变。由于式子(2)是对 $A_t$ 的期望值，因此即使在期望值中加入函数 $b(S_t)$ ，等式也成立。

\mybox[blue]{NOTE}{
动作 $A_t$ 的变化会导致收益 $G_t$ 的变化，因此以下式子不成立。
$$\mathbb{E}_{A_t\sim\pi_\theta}\left\lbrack{G_t\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack = 0$$
}

式子(2)在整个 $t=0\sim T$ 的范围都成立，所以可以得到以下式子。

$$
\mathbb{E}_{A_t\sim\pi_\theta}\left\lbrack{\sum_{t=0}^Tb(S_t)\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack = 0
$$

所以基线证明完毕。

\section{总结}

在本章中，我们学习了基于策略的方法——策略梯度法。具体来说，我们学习了 4 种策略梯度法的算法。它们的统一的数学式如下所示。

$$
\nabla_\theta J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\left\lbrack{\sum_{t=0}^T\Phi_t\nabla_\theta\log\pi_\theta(A_t|S_t)}\right\rbrack
$$

\begin{tabular}{lll}
1. & $\Phi_t=G(\tau)$                             & （最简单的策略梯度法） \\
2. & $\Phi_t=G_t$                                 & （REINFORCE） \\
3. & $\Phi_t=G_t-b(S_t)$                          & （带基线的REINFORCE） \\
4. & $\Phi_t = R_t + \gamma V(S_{t+1})-V(S_t)$    & （Actor-Critic） \\
5. & $\Phi_t = A_t^{\text{GAE}}$                  & （广义优势估计）
\end{tabular}


上面几种方法的权重 $\Phi_t$ 各不相同。最简单的策略梯度法在所有时刻的权重都是 $G_\tau$ 。对它进行改进，将时刻 $t$ 的收益 $G_t$ 作为权重进行评估的是REINFORCE。另外，通过加入``基线''这一方法，减小了方差的方法是带基线的REINFORCE。Actor-Critic是一种除了策略之外，对价值函数也用神经网络建模的方法。期待 $(1)\rightarrow(2)\rightarrow(3)\rightarrow(4)\rightarrow(5)$ 这样的编号一直延续下去，从而有更高级的方法出现，产生更好的结果。

\begin{marker}
$\Phi_t$也叫做优势函数（Advantage Function），优势函数经常在文献中表示为$A(s,a)$，也就是在状态 $s$ 采取动作 $a$ 时，策略的优势是多少。

强化学习中的很多花活儿都是针对如何改进$\Phi_t$而来的。比如GRPO算法使用的\textbf{组相对策略优势}。
\end{marker}

也就是，我们在梯度上升的时候，先周围看一圈，然后找一个安全的步长，然后进行梯度上升。

为了实现这个目的，我们的梯度公式 $\nabla_\theta J(\theta)$ 就要改变了。

PPO算法是Actor-Critic架构的，也就是演员-评论家架构。

所以我们先来回顾一下策略梯度法的演员-评论家架构的梯度公式。

策略梯度法的目标函数

$$
J(\theta) = \mathbb{E}_{\tau\sim\pi_{\theta}}[G(\tau)]
$$

策略梯度法的目标函数的梯度

$$
\nabla_{\theta}J(\theta)=\mathbb{E}_{\tau\sim\pi_{\theta}}\left[\sum_{t=0}^TA_t^{\pi_\theta}\nabla_{\theta}\log\pi_{\theta}(a_t|s_t)\right]
$$

其中 $A_t^{\pi_\theta}$ 为估计的优势。这里的 $A$ 表示优势，也就是Advantage。表示当前策略采取动作 $A_t$ 之后，相对于价值函数评估的价值的优势是多少。

\begin{marker}
为了不和前面的公式混淆，我们将动作的数学符号由$A_t$改为$a_t$，将状态的数学符号由$S_t$改为$s_t$。这样$A$就代表优势了。
\end{marker}

而PPO的目标函数变成了式\ref{eq:ppo-clip-objective-function}：

\begin{theorem}{带裁剪的PPO目标函数}{}
\begin{equation}\label{eq:ppo-clip-objective-function}
J(\theta)^{\text{ppo-clip}}=\mathbb{E}_{\tau\sim\pi_{{_\theta}_{\text{old}}}}\left[{\sum_{t=0}^T\left[\min\left(\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}A_t^{\pi_{\text{old}}},\text{clip}\left(\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)},1-\epsilon,1+\epsilon\right)A_t^{\pi_{\text{old}}}\right)\right]}\right]
\end{equation}
\end{theorem}

只要计算出这个目标函数，然后进行反向传播（求$\nabla_\theta{J(\theta)^{\text{ppo-clip}}}$）就可以更新策略神经网络了。

我们有6种不同的情况，见表\ref{tbl:ppo-ratio}。首先记住，我们取裁剪目标和非裁剪目标中的最小值。

\begin{itemize}
\item \textbf{情况 1 和 2：比率介于裁剪范围之内}

在情况1和2中，由于比例介于范围$[1-\epsilon,1+\epsilon]$之间，因此目标函数不会被裁剪。

在情况 1 中，我们具有正优势：该动作优于该状态下所有动作的平均值。因此，我们应该鼓励当前策略提高在该状态下采取该动作的概率。

由于该比率是在区间之间的，因此我们可以增加我们的策略在该状态下采取该行动的概率。

在情况 2 中，我们有一个负优势：该动作比该状态下所有动作的平均值更差。因此，我们应该阻止当前策略在该状态下采取该动作。

由于该比率是在区间之间的，因此我们可以降低我们的策略在该状态下采取该行动的概率。

\item \textbf{情况 3 和 4：比率小于$1-\epsilon$}

如果概率比低于$1-\epsilon$，则当前策略在该状态下采取该行动的概率比旧策略低得多。

如果像情况 3 中一样，优势估计为正（$A>0$），那么我们希望增加在该状态下采取该行动的概率。

但是，如果像情况 4 那样，优势估计为负，我们不想进一步降低在该状态下采取该行动的概率。因此，$\text{梯度} = 0$（因为我们在一条平线上），所以我们不会更新权重。

\item \textbf{情况 5 和 6：比率大于$1+\epsilon$}

如果概率比高于$1+\epsilon$，则当前策略中该状态下采取该行动的概率远高于前一策略。

如果像情况 5 那样，优势为正，我们不应该太贪心。因为在当前状态下，我们采取该行动的概率已经比之前的策略更高了。因此，梯度 = 0（因为我们在一条平线上），所以我们不会更新权重。

如果像情况 6 中那样，优势是负的，我们希望降低在该状态下采取该行动的概率。
\end{itemize}


总结一下，我们只用未裁剪的目标函数部分来更新策略。当最小值是裁剪后的目标函数部分时，我们不会更新策略权重，因为梯度将等于0。

因此，我们仅在以下情况下更新我们的策略：

\begin{itemize}
\item 比率在 $(1-\epsilon,1+\epsilon)$ 之内
\item 比率不在 $(1-\epsilon,1+\epsilon)$ 范围内，但优势使我们更接近这个范围。
\begin{itemize}
	\item 比率小于 $1-\epsilon$ ，但优势 > 0 。
	\item 比率大于 $1+\epsilon$ ，但优势 < 0 。
\end{itemize}
\end{itemize}

你可能会想，为什么当最小值是截断比率时，梯度为0。当比率被截断时，在这种情况下的导数将不是 $p_t(\theta)A_t$ 的导数。而是 $(1-\epsilon)A_t$ 或者 $(1+\epsilon)A_t$ 的导数，而两者的导数都是0。

\begin{marker}
$A_t$不是$\theta$的函数。所以对$\theta$求导为0。
\end{marker}

总而言之，得益于这个裁剪的替代目标函数（替换了原来的简单优美的目标函数（$J(\theta)=\mathbb{E}_{\tau\sim\pi_{\theta}}[G(\tau)]$），我们限制了当前策略与旧策略之间的差异范围。因为我们消除了比率超出区间的诱因，因为裁剪会对梯度产生影响。如果比率为$>1+\epsilon$或$<1-\epsilon$，则梯度将等于$0$。

PPO增加了一个软约束（裁剪机制），可以通过一阶优化器（求一阶导数）进行优化。我们偶尔可能会做出一些错误的决策，但它在优化速度上取得了良好的平衡。实验结果证明，这种平衡能够以最简单的方式实现最佳性能。

\section{带裁剪的PPO算法的伪代码}

\begin{algorithm}
\caption{带裁剪目标的PPO}\label{algo:ppo-clip}
\begin{algorithmic}[1]
\State 输入：初始化策略参数 $\theta_0$ ，初始化裁剪阈值参数 $\epsilon$
\For{$k = 0,1,2,\dots$}
\State 使用策略 $\pi_k=\pi(\theta_k)$ 采集一组轨迹数据 $\mathcal{D}_k$
\State 计算优势 $A_t^{\pi_k}$\Comment{使用广义优势估计（GAE）}
\State 计算策略的更新\Comment{执行K步的微批次SGD，使用Adam优化器}
\State $\theta_{k+1}=\theta_k+\alpha\nabla_{\theta_k}J(\theta_k)^{\text{ppo-clip}}$
\State 其中
$$
J(\theta_k)^{\text{ppo-clip}}=\underset{\tau\sim\pi_k}{\mathbb{E}}\left[{\sum_{t=0}^T[\min(p_t(\theta)A_t^{\pi_k},\text{clip}(p_t(\theta),1-\epsilon,1+\epsilon)A_t^{\pi_k})]}\right]
$$
\EndFor
\end{algorithmic}
\end{algorithm}

        super().__init__()
        self.l1 = nn.Linear(4, 128)

class Agent:
    def __init__(self):
        self.gamma = 0.98
        self.lr_pi = 0.001
        self.lr_v = 0.02
        self.action_size = 2

        self.pi = PolicyNet(self.action_size)
        self.v = ValueNet()

        self.optimizer_pi = optim.Adam(self.pi.parameters(), lr=self.lr_pi)
        self.optimizer_v = optim.Adam(self.v.parameters(), lr=self.lr_v)

    def get_action(self, state):
        state = torch.tensor(state[np.newaxis, :])
        probs = self.pi(state)
        probs = probs[0]
        m = Categorical(probs)
        action = m.sample().item()
        return action, probs

    def collect_trajectory(self, env):
        """采集一条轨迹"""
        state = env.reset()
        states, next_states, actions, action_probs, rewards, dones = [], [], [], [], [], []
        done = False

        while not done:
            action, probs = self.get_action(state)
            next_state, reward, done, _ = env.step(action)
            states.append(state) # β$s_t$β
            actions.append(action) # β$a_t$β
            action_probs.append(probs[action]) # β$\pi(a_t|s_t)$β
            next_states.append(next_state) # β$s_{t+1}$β
            rewards.append(reward) # β$R_t$β
            dones.append(done) # β$\text{done}_t$β
            state = next_state # 状态转移

        return states, next_states, actions, action_probs, rewards, dones
\end{codebox}

接下来我们要实现智能体的更新（\py{update}）代码，在PPO算法中，我们需要用到旧策略采样的轨迹。所以需要保存旧策略采样的轨迹的完整信息。

我们采样的轨迹是：

$$
\tau = \left[ s_0, a_0, R_0, s_1, a_1, R_1, \dots, s_T, a_T, R_T \right]
$$

那么我们使用元组来保存一条轨迹的信息。结构如下

$$
\text{一条轨迹的详细信息}
=
\begin{cases}
\text{states}: \left[ s_0, s_1, \dots, s_{T-1} \right] \\
\text{next\_states}: \left[ s_1, s_2, \dots, s_T \right] \\
\text{actions}: \left[ a_0, a_1, \dots, a_{T-1} \right] \\
\text{action\_probs}: \left[ \pi_{\theta_\text{old}}(a_0|s_0), \pi_{\theta_\text{old}}(a_1|s_1), \dots, \pi_{\theta_\text{old}}(a_{T-1}|s_{T-1}) \right] \\
\text{rewards}: \left[ R_0, R_1, \dots, R_{T-1} \right] \\
\text{dones}: \left[ \text{False}, \text{False}, \dots, \text{True} \right]
\end{cases}
$$

有了旧策略采样的轨迹的所有详细信息，我们就可以来实现PPO算法了。

\begin{codebox}{python}{PPO-Agent-2}
class Agent:
    ...

    def update(self, trajectory):
        states, next_states, actions, action_probs, rewards, dones = trajectory
        # β$[s_0,s_1,\dots,s_{T-1}]$β
        states = torch.tensor(states)
        # β$[a_0,a_1,\dots,a_{T-1}]$β
        actions = torch.tensor(actions).view(-1, 1)
        # β$[R_0,R_1,\dots,R_{T-1}]$β
        rewards = torch.tensor(rewards).view(-1, 1)
        # β$[s_1,s_2,\dots,s_T]$β
        next_states = torch.tensor(next_states)
        # β$[\text{False}_1, \text{False}_2, \dots, \text{True}_T]$β
        dones = torch.tensor(dones, dtype=torch.float).view(-1, 1)
        # β$[V(s_0),V(s_1),\dots,V(s_{T-1})]$β
        V = self.v(states).detach()
        # β$\text{TD-target}_t=R_t+\gamma V(s_{t+1})$β
        # β$[\text{TD-target}_0, \text{TD-target}_1, \dots, \text{TD-target}_{T-1}]$β
        td_target = rewards + self.gamma * self.v(next_states) * (1 - dones)
        # 一步TD误差：β$\delta_t=R_t+\gamma V(s_{t+1})-V(s_t)$β
        # β$[\delta_0, \delta_1, \dots, \delta_{T-1}]$β
        td_delta = td_target - V
        # 计算每个时刻t的广义优势估计（GAE）
        # β$[A^{\text{GAE}}_0,A^{\text{GAE}}_1,\dots,A^{\text{GAE}}_{T-1}]$β
        gae = compute_gae(self.gamma, td_delta.cpu())
        # 冻结一份旧策略采取动作的对数概率β$\log{\pi_{\theta_\text{old}}(a_t|s_t)}$β
        # β$[\log{\pi_{\theta_\text{old}}(a_0|s_0)},\log{\pi_{\theta_\text{old}}(a_1|s_1)}],\dots,\log{\pi_{\theta_\text{old}}(a_{T-1}|s_{T-1})}$β
        old_probs = torch.tensor(action_probs).view(-1, 1)
        old_log_probs = torch.log(old_probs).detach()
        # 每条轨迹使用10次，也就是更新10次策略网络
        for _ in range(10):
            # 新策略采取动作的对数概率：β$\log{\pi_\theta(a_t|s_t)}$β
            # β$[\log{\pi_\theta(a_0|s_0)},\log{\pi_\theta(a_1|s_1)},\dots,\log{\pi_\theta(a_{T-1}|s_{T-1})}]$β
            log_probs = torch.log(self.pi(states).gather(1, actions))
            # 计算比率：β$p_t(\theta)=\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}$β
            ratio = torch.exp(log_probs - old_log_probs)
            # β$p_t(\theta)A^{\pi_{\theta_\text{old}}}_t$β
            # β$[p_0A^{\pi_{\theta_\text{old}}}_0,p_1A^{\pi_{\theta_\text{old}}}_1,\dots,p_{T-1}A^{\pi_{\theta_\text{old}}}_{T-1}]$β
            surr1 = ratio * gae
            # β$\text{clip}(p_t(\theta),1-\epsilon,1+\epsilon)A^{\pi_{\theta_\text{old}}}_t|_{\epsilon=0.2}$β
            # β$[\text{clip}(p_0)A^{\text{GAE}}_0,\text{clip}(p_1)A^{\text{GAE}}_1,\dots,\text{clip}(p_{T-1})A^{\text{GAE}}_{T-1}]$β
            surr2 = torch.clamp(ratio, 1 - 0.2, 1 + 0.2) * gae
            # β$\pi_\text{loss}=-\frac{1}{T}\displaystyle\sum_{t=0}^{T-1}\min(\text{surr1}_t,\text{surr2}_t)$β
            pi_loss = torch.mean(-torch.min(surr1, surr2))
            # β$V_{\text{loss}}=\frac{1}{T}\displaystyle\sum_{t=0}^{T-1}\left(V(s_t)-\left(A_t^{\text{GAE}}+V(s_t)\right)\right)$β
            v_loss = torch.mean(F.mse_loss(self.v(states), gae + V))
            self.optimizer_pi.zero_grad()
            self.optimizer_v.zero_grad()
            pi_loss.backward()
            v_loss.backward()
            self.optimizer_pi.step()
            self.optimizer_v.step()
\end{codebox}

\begin{marker}
比值的计算方法：因为$A=e^{\log{A}}$，所以有，$\frac{A}{B}=e^{\log{A}-\log{B}}=\frac{e^{\log{A}}}{e^{\log{B}}}$
\end{marker}

def compute_gae(gamma, td_delta):
    # β$\delta_t$β
    td_delta = td_delta.detach().numpy()
    gae_list = []
    last_gae = 0.0
    lmbda = 0.95
    # β$A_t=\delta_t+\gamma\lambda A_{t+1}$β
    for delta in td_delta[::-1]:
        last_gae = gamma * lmbda * last_gae + delta
        gae_list.append(last_gae)
    gae_list.reverse()

\chapter{近端策略优化背后的数学理论}

在使用策略梯度算法训练智能体时，一个挑战是它们容易出现性能崩溃：智能体会突然表现很差。这种情况很难恢复，因为智能体会开始生成质量较差的轨迹，而这些轨迹又被用于进一步训练策略。我们还看到，on-policy（同策略）算法的样本效率较低，因为它们无法重用数据。

Schulman等人提出的近端策略优化（Proximal Policy Optimization, PPO）是一类优化算法，用来解决这两个问题。PPO的核心思想是在目标函数中引入一个代理（surrogate）目标，它通过保证策略的单调改进来避免性能崩溃。该目标还有一个好处，就是可以在训练过程中重用离策略（off-policy）数据。

PPO可以通过将原始的目标函数 $J(\theta)$ 替换为修改后的 PPO 目标，来扩展 REINFORCE 或者 Actor-Critic。此修改带来了更稳定、且样本效率更高的训练过程。

在本章中，我们首先讨论性能崩溃问题。随后通过单调改进理论来应对该问题。我们将该理论应用于策略梯度目标，将其改造为一个代理目标。

在介绍完理论基础后，我们讨论 PPO 算法。

\section{一些数学知识}

\subsection{KL散度}

KL散度（Kullback-Leibler Divergence, KLD）非常重要。

假设有一个连续型随机变量 $x$ ，其概率密度表示为 $p(x)$ 。此时，函数 $f(x)$ 的期望值可以用下面的数学式表示。

\begin{equation}
\mathbb{E}_{p(x)}[f(x)]=\int f(x)p(x)dx
\end{equation}

关于概率分布 $q(x)$ 的期望值可以用下面的数学式表示。

\begin{equation}
\mathbb{E}_{q(x)}[f(x)]=\int f(x)q(x)dx
\end{equation}

\textbf{KL散度的定义}

衡量两个概率分布之间差异的一种方法是KL散度。当给定两个概率分布 $p(x)$ 和 $q(x)$ 时，KL散度可以用下面的数学式表示。

\begin{definition}{连续型随机变量的KL散度}{}
\begin{equation}
D_{KL}(p\Vert q)=\int p(x)\log\frac{p(x)}{q(x)}dx
\end{equation}
\end{definition}

上面的式子是当 $x$ 为连续型随机变量时的KL散度。当 $x$ 为离散型随机变量时，数学式如下所示。

\begin{definition}{离散型随机变量的KL散度}{}
\begin{equation}
D_{KL}(p\Vert q)=\sum_x p(x)\log\frac{p(x)}{q(x)}
\end{equation}
\end{definition}

KL散度具有以下特性：

\begin{itemize}
\item 两个概率分布的差异越大，KL散度的值就越大
\item KL散度的值大于或等于0，且仅当两个概率分布相同时，其值才为0
\item KL散度是非对称的衡量指标，因此 $D_{KL}(p\Vert q)$ 和 $D_{KL}(q\Vert p)$ 的值不同
\end{itemize}

这些特性使得 KL 散度可以用来衡量两个概率分布的差异程度。下面我们通过具体的例子来了解这些特性。这里以抛硬币为例进行说明。假设一枚硬币正面朝上和反面朝上的概率是确定的，如表\ref{tbl:real-coin-distribution}所示。

\end{table}

表\ref{tbl:real-coin-distribution}是硬币的``真实概率分布''，在这里我们用符号 $p$ 来表示。假设有人对这枚硬币的概率分布做了如下估计。

\subsection{信息论}

信息量（Self-Information）：

\begin{itemize}
\item 一个事件发生的信息量定义为：$I(x) = -\log P(x)$
\item 概率越小的事件，包含的信息量越大
\item 例如："太阳从东边升起"（高概率）vs "中彩票"（低概率）
\end{itemize}

熵（Entropy）：

\begin{itemize}
\item 衡量随机变量的不确定性：$H(P) = -\sum_{i} P(x_i) \log P(x_i)$
\item 熵越大，不确定性越大
\end{itemize}

交叉熵（Cross-Entropy）：

\begin{itemize}
\item 衡量两个概率分布之间的差异：$H(P, Q) = -\sum_{i} P(x_i) \log Q(x_i)$
\item 其中 $P$ 是真实分布，$Q$ 是预测分布
\end{itemize}

\textbf{极大似然估计和交叉熵}

假设我们有训练数据 ${(x_1, y_1), (x_2, y_2), ..., (x_n, y_n)}$，其中 $y_i$ 是真实标签。

似然函数：

\begin{equation}
L(\theta) = \prod_{i=1}^{n} P(y_i | x_i; \theta)
\end{equation}

对数似然：

\begin{equation}
\log L(\theta) = \sum_{i=1}^{n} \log P(y_i | x_i; \theta)
\end{equation}

最大化对数似然 = 最小化负对数似然：

\begin{equation}
\text{Loss} = -\frac{1}{n}\sum_{i=1}^{n} \log P(y_i | x_i; \theta)
\end{equation}

这就是\textbf{交叉熵损失}！

\textbf{KL散度和交叉熵}

KL散度衡量两个分布的差异：

\begin{equation}
D_{KL}(P||Q) = \sum_{i} P(x_i) \log \frac{P(x_i)}{Q(x_i)} = \sum_{i} P(x_i) \log P(x_i) - \sum_{i} P(x_i) \log Q(x_i)
\end{equation}

\begin{equation}
D_{KL}(P||Q) = -H(P) + H(P,Q)
\end{equation}

\begin{equation}
\frac{\partial D_{KL}(P\Vert Q)}{\partial\theta} = \frac{\partial H(P, Q)}{\partial \theta}
\end{equation}

其中：

\begin{itemize}
\item $H(P) = -\sum_{i} P(x_i) \log P(x_i)$ 是真实分布的熵（常数）
\item $H(P,Q) = -\sum_{i} P(x_i) \log Q(x_i)$ 是交叉熵
\end{itemize}

最小化KL散度 = 最小化交叉熵（因为真实分布的熵是常数）

\subsection{重要性采样}

重要性采样利用从其他概率分布中采样的数据来计算某个概率分布的期望值。为了说明重要性采样，下面来看一个计算期望值$\mathbb{E}_\pi[x]$的简单例子。设$x$是随机变量，$x$的概率用$\pi(x)$表示。期望值的式子如下所示。

\begin{equation}
\mathbb{E}_\pi[x] = \sum x \pi(x)
\end{equation}

我们先复习一下学过的内容。为了用蒙特卡洛方法近似这个期望值，我们从概率分布$\pi$对$x$进行采样，并取其平均值。数学式如下所示：

\begin{equation}
\begin{aligned}
\text{采样}: x^{(i)}\sim\pi\quad (i=1,2,\cdots,n) \\
\mathbb{E}_\pi[x]\simeq\frac{x^{(1)}+x^{(2)}+\cdots+x^{(n)}}{n}
\end{aligned}
\end{equation}

式子中的符号$x^{(i)}\sim\pi$表示第$i$个数据$x(i)$是从概率分布$\pi$中采样的。

接下来回到正题。我们现在探讨的是从别的概率分布中采样$x$的场景。假设$x$是从概率分布$b$（而不是$\pi$）中采样的。在这种情况下，期望值$\mathbb{E}_\pi[x]$如何被近似呢？解决这个问题的关键在于下面这个式子的变形。

\begin{equation}
\begin{aligned}
\mathbb{E}_\pi[x] &= \sum x\pi(x) \\
&= \sum x \frac{b(x)}{b(x)}\pi(x) \\
&= \sum x \frac{\pi(x)}{b(x)}b(x)
\end{aligned}
\end{equation}

这里的要点是插入$\frac{b(x)}{b(x)}$。$\frac{b(x)}{b(x)}$总是为$1$，所以等式成立。然后，我们将式子变为$\sum\cdots b(x)$的形式，如上面的式子所示，这样它就可以被视为概率分布$b(x)$的期望值了。实际上对上面的式子变形，可以得到以下式子。

\begin{equation}
\begin{aligned}
\mathbb{E}_\pi[x] &= \sum x\frac{\pi(x)}{b(x)}b(x) \\
&= \mathbb{E}_b\left[ x\frac{\pi(x)}{b(x)} \right] 
\end{aligned}
\end{equation}

这里需要注意的是式子中的$\mathbb{E}_b$，它表示的是概率分布$b$的期望值。另外每个$x$都要乘以$\frac{\pi(x)}{b(x)}$这一点也很重要。如果$\rho(x)=\frac{\pi(x)}{b(x)}$，那么我们就可以把式子看作每个$x$都乘以权重$\rho(x)$。根据以上探讨，基于式的蒙特卡洛方法如下所示。

\begin{equation}
\begin{aligned}
\text{采样}: x^{(i)}\sim b\quad (i=1,2,\cdots,n) \\
\mathbb{E}_\pi[x]\simeq\frac{\rho(x^{(1)})+\rho(x^{(2)})+\cdots+\rho(x^{(n)})}{n}
\end{aligned}
\end{equation}

这样我们就使用从不同于$\pi$的概率分布$b$中采样的数据计算出了$\mathbb{E}_\pi[x]$。下面来实现重要性采样的代码 。这里我们对图\ref{fig:importance-sampling-1}所示的概率分布进行重要性采样。

\begin{itemize}
    \item 由于$3$是概率分布$\pi$的代表值，因此本来它应该被更频繁地采样。
    \item 但在概率分布$b$中，$3$这个值并不经常出现。
    \item 为了填补这个落差，当$3$被采样时，它会被调整为乘以权重，从而使该值变得更大。
\end{itemize}

考虑到概率分布$\pi$和$b$之间的差异，我们将采样值乘以其权重来调整采样值，这么做是合理的。可是，明明采样的值是$3$，它却被当作了$7.2$，如果这是第一个采样数据，那么此时的估计值就是$7.2$。与真正的值$2.7$相比，$7.2$的偏离较大。因此，通过权重$\rho$对实际得到的值的填补越大，方差与真正的值的差异就越大。

    rho = pi[i] / b[i] # β$\rho$β
    samples.append(rho * s)

mean = np.mean(samples)
var = np.var(samples)
print("IS: {:.2f} (var: {:.2f})".format(mean, var))
\end{codebox}

因此，在进行重要性采样时，可以通过使两个概率分布更加接近来减小方差。不过，强化学习的重点是让一个策略（概率分布）进行``探索''，另一个策略进行``利用''。在满足这个条件的基础上，就可以通过使两个概率分布尽可能地接近来减小方差了。

\section{替代目标}

在本节中，我们将介绍用于 PPO 算法的代理（surrogate）目标。首先，我们通过讨论性能崩溃问题来引出这一动机。随后我们将看到如何修改原始的策略梯度目标以避免该问题。

\subsection{性能崩溃}

在我们对策略梯度算法的讨论中，我们看到，通过使用策略梯度 $\nabla_{\theta}J(\theta)$ 来改变策略参数 $\theta$，即可优化策略 $\pi_{\theta}$。这是一种间接的方法，因为我们是在一个无法直接控制的策略空间中搜索最优策略。要理解原因，我们首先需要区分策略空间与参数空间。

在优化过程中，我们在所有策略的集合中搜索一系列策略 $\pi_{1}, \pi_{2}, \pi_{3},\dots,\pi_{n}$。这个集合被称为策略空间 $\Pi$。

\begin{equation}\label{eq:policy-space}
\Pi = \left\{ \pi_{i} \right\} 
\end{equation}

当策略被参数化为 $\pi_{\theta}$ 时，我们也可以方便地表示参数 $\theta$ 的参数空间。每一个唯一的 $\theta$ 都对应着一个策略实例。参数空间记为 $\Theta$。

\begin{equation}\label{eq:parameters-space}
\Theta=\left\{ \theta\in \mathbb{R}^m, \text{其中}\; m \;\text{是策略模型的参数数量} \right\} 
\end{equation}

尽管目标函数 $J(\pi_{\theta})$ 是用策略空间中的策略 $\pi_{\theta}\in\Pi$ 所生成的轨迹来计算的，但对最优策略的搜索实际上是在参数空间中通过寻找合适的参数 $\theta\in\Theta$ 来进行的。也就是说，我们的可控量在 $\Theta$，而结果体现在 $\Pi$。在实践中，我们用学习率 $\alpha$ 来控制参数更新的步长，如等式 \ref{eq:parameters-update-step} 所示。

\begin{equation}\label{eq:parameters-update-step}
\Delta\theta=\alpha \nabla _{\theta}J(\pi_{\theta})
\end{equation}

不幸的是，策略空间与参数空间并不总是同构映射，两者的距离也不一定对应。以两对参数 $(\theta_{1},\theta_{2})$ 和 $(\theta_{2},\theta_{3})$ 为例，假设它们在参数空间中的距离相同，即 $d_{\theta}(\theta_{1},\theta_{2})=d_{\theta}(\theta_{2},\theta_{3})$。然而，它们映射得到的策略对 $(\pi_{\theta_{1}},\pi_{\theta_{2}})$ 与 $(\pi_{\theta_{2}}, \pi_{\theta_{3}})$ 的距离未必相同。也就是说，

\begin{equation}
d_{\theta}(\theta_{1},\theta_{2})=d_{\theta}(\theta_{2},\theta_{3})\nLeftrightarrow d_{\pi}(\pi_{\theta_{1}},\pi_{\theta_{2}})=d_{\pi}(\pi_{\theta_{2}},\pi_{\theta_{3}})
\end{equation}

这带来了潜在问题：参数更新的理想步长 $\alpha$ 难以确定。事先并不清楚它在策略空间 $\Pi$ 中会对应多小或多大的步幅。若 $\alpha$ 过小，就需要很多次迭代，训练会很慢，且策略可能陷入某个局部最优。若 $\alpha$ 过大，策略空间中的对应步长可能越过优良策略的邻域，导致性能崩溃。一旦发生这种情况，新策略会更差，用它生成的轨迹数据也会很差，从而用于下一次更新，进而破坏后续的策略迭代。因此，性能崩溃往往很难恢复。

一般而言，恒定步长并不能避免这些问题。在梯度上升 $\theta\leftarrow\theta+\alpha \nabla_{\theta} J(\pi_{\theta})$ 中，学习率 $\alpha$ 通常是固定的或按计划衰减的，只有方向 $\nabla_{\theta}J(\pi_{\theta})$ 在变化。然而，由于映射是非等距的，恒定步长在映射到 $\Pi$ 时仍可能对应为不同的距离。

最优的 $\alpha$ 选择会随当前策略 $\pi_{\theta}$ 在策略空间 $\Pi$ 中的位置，以及当前参数 $\theta$ 从其在 $\Theta$ 的邻域映射到 $\Pi$ 中 $\pi_{\theta}$ 邻域的方式而变化。理想情况下，算法应能根据这些因素自适应地调整参数步长。

为了基于参数空间中的一次具体更新将如何影响策略空间来推导自适应步长，我们首先需要一种度量，用于衡量两个策略之间性能差异。

\subsection{修改目标函数}

本节我们引入\textbf{相对策略性能恒等式}（relative policy performance identity），用于度量两个策略之间的性能差异。随后展示如何利用该恒等式改造策略梯度目标，从而在优化过程中保证性能的单调提升。

直观上，问题出在步长上，因此可以通过加入一个约束，将步长限制在安全范围以防止性能崩塌。施加恰当的约束后，我们可以推导出所谓的\textbf{单调改进理论}（Monotonic Improvement Theory）。

首先，给定一个策略$\pi$，其参数更新后的下一次迭代为$\pi'$。我们将相对策略性能恒等式定义为二者目标函数的差值，如式\ref{eq:two-policy-diff}所示。需要注意，优势函数 $A^{\pi}(s_t,a_t)$ 始终使用旧策略 $\pi$ 来计算。

\begin{equation}
J(\pi')-J(\pi)=\mathbb{E}_{\tau\sim\pi'}\left[ \sum^T_{t=0}\gamma^tA^\pi(s_t,a_t) \right]\label{eq:two-policy-diff}
\end{equation}

\mybox[blue]{公式\ref{eq:two-policy-diff}的证明}{
从反方向证明
\begin{align}
& \mathbb{E}_{\tau\sim\pi'}\left[ \sum_{t\geq 0}\gamma^tA^\pi(s_t,a_t) \right]\label{eq:two-policy-proof-1} \\
&= \mathbb{E}_{\tau\sim\pi'}\left[ \sum_{t\geq 0}\gamma^t(R_t+\gamma V^{\pi}(s_{t+1})-V^{\pi}(s_t)) \right]\label{eq:two-policy-proof-2} \\
&= \mathbb{E}_{\tau\sim\pi'}\left[ \sum_{t\geq 0}\gamma^tR_t+\sum_{t\geq 0}\gamma^{t+1}V^{\pi}(s_{t+1})-\sum_{t\geq 0}\gamma^tV^{\pi}(s_t) \right]\label{eq:two-policy-proof-3} \\
&= \mathbb{E}_{\tau\sim\pi'}\left[ \sum_{t\geq 0}\gamma^tR_t\right] + \mathbb{E}_{\tau\sim\pi'}\left[\sum_{t\geq 0}\gamma^{t+1}V^{\pi}(s_{t+1})-\sum_{t\geq 0}\gamma^tV^{\pi}(s_t) \right]\label{eq:two-policy-proof-4} \\
&= J(\pi') + \mathbb{E}_{\tau\sim\pi'}\left[\sum_{t\geq 1}\gamma^{t}V^{\pi}(s_{t})-\sum_{t\geq 0}\gamma^tV^{\pi}(s_t) \right]\label{eq:two-policy-proof-5} \\
&= J(\pi') - \mathbb{E}_{\tau\sim\pi'}\left[ V^\pi(s_0) \right]\label{eq:two-policy-proof-6} \\
&= J(\pi') - \mathbb{E}_{\tau\sim\pi'}\left[ J(\pi) \right]\label{eq:two-policy-proof-7} \\
&= J(\pi') - J(\pi)\label{eq:two-policy-proof-8}
\end{align}
公式\ref{eq:two-policy-proof-6}到公式\ref{eq:two-policy-proof-7}的推导依赖了状态价值函数的定义：$V^\pi(s_0)=\mathbb{E}_{\tau\sim\pi}[\sum_{t\geq 0}\gamma^tR_t]=\mathbb{E}_{\tau\sim\pi}[G(\tau)]=J(\pi)$。公式\ref{eq:two-policy-proof-7}到公式\ref{eq:two-policy-proof-8}的推导依赖了期望的性质，也就是由于策略$\pi$和$\pi'$相互独立，所以$\mathbb{E}_{\tau\sim\pi'}[J(\pi)]=J(\pi)$。
}

相对策略性能恒等式 $J(\pi')-J(\pi)$ 可作为度量策略改进的指标。若该差值为正，则新策略 $\pi'$ 比旧策略 $\pi$ 更优。在一次策略迭代过程中，理想情况下应选择使这一差值最大化的新策略$\pi$。因此，最大化目标 $J(\pi')$ 等价于最大化该恒等式，两者均可通过梯度上升实现。

\begin{equation}
\max_{\pi'}{J(\pi')}\Longleftrightarrow\max_{\pi'}{\left(J(\pi')-J(\pi)\right)}
\end{equation}

以这种方式刻画目标也意味着，每次策略迭代都应保证非负（单调）的改进——即 $\left(J(\pi')-J(\pi)\right)\geq 0$——因为在最坏情况下我们可以简单地令$\pi'=\pi$，也就是不改进策略。在此条件下，整个训练过程中将不会发生性能崩塌，这正是我们所期望的性质。

然而，这一恒等式作为目标函数有一个限制使其无法直接使用。注意，在表达式 $\mathbb{E}_{\tau\sim\pi'}\left[ \sum_{t\geq 0}A^\pi(s_t,a_t) \right]$ 中，期望要求使用新策略$\pi'$采样轨迹以进行更新，但在完成更新之前，新策略$\pi'$并不可用。为了解决这一悖论，我们需要设法将其改写为使用已可用的旧策略$\pi$。

为此，我们可以假设相邻的策略$\pi$与$\pi'$彼此较为接近（可通过较低的 KL 散度来度量），从而它们产生的状态分布也相似。

这样，公式\ref{eq:two-policy-diff}就可以用旧策略采样的轨迹$\tau\sim\pi$来近似了。具体近似的手段就是使用\textbf{重要性采样}，我们使用的重要性采样权重为$\frac{\pi'(a_t|s_t)}{\pi(a_t|s_t)}$。也就是我们使用新旧策略采取动作的概率的比值来改进旧策略$\pi$产生的轨迹的回报值。在新策略 $\pi'$ 下更可能发生的动作所对应的回报会被上调权重，而在 $\pi'$ 下相对不太可能的动作所对应的回报会被下调权重。该近似在式\ref{eq:cpi}中给出。

\begin{equation}\label{eq:cpi}
\begin{aligned}
J(\pi')-J(\pi) &= \mathbb{E}_{\tau\sim{\color{red}\pi'}}\left[ \sum_{t\geq 0}A^\pi(s_t,a_t) \right] \\
& \approx \mathbb{E}_{\tau\sim{\color{red}\pi}}\left[ \sum_{t\geq 0}A^\pi(s_t,a_t){\color{red}\frac{\pi'(a_t|s_t)}{\pi(a_t|s_t)}} \right] \\
&= J^{\text{CPI}}_\pi(\pi')
\end{aligned}
\end{equation}

式\ref{eq:cpi}也就是新目标右手边的$J^{\text{CPI}}_\pi(\pi')$叫做\textbf{替代目标}（surrogate objective）。因为新目标中包含了新旧策略的比值，所以叫做``替代目标''。上标CPI的意思是``保守策略迭代''（conservative policy iteration）。

现在我们有了一个新的目标函数。要将其用于策略梯度算法，需要检查在该目标下进行优化是否仍然是在执行策略梯度上升。幸运的是，我们可以证明替代目标的梯度等于策略梯度，如式\ref{eq:cpi-gradient}所述。

\begin{equation}\label{eq:cpi-gradient}
\nabla_\theta J^{\text{CPI}}_{\theta_\text{old}}(\theta)|_{\theta_{\text{old}}} = \nabla_\theta J(\pi_\theta)|_{\theta_{\text{old}}}
\end{equation}

\mybox[blue]{公式\ref{eq:cpi-gradient}的证明}{
在这里，我们将证明代理目标的梯度等于策略梯度，即式\ref{eq:cpi-gradient}所述。
\newline
我们从对 $J^\text{CPI}_\pi(\pi')$ 求梯度开始。为此，需要将变量 $\theta$ 显式写出。具体来说，把新策略 $\pi'$ 写作变量 $\pi_\theta$，而把旧策略$\pi$写作常量$\pi_{\theta_\text{old}}$，并在$\pi_{\theta_\text{old}}$处计算梯度，记作$|_{\theta_\text{old}}$（这是必要的，因为$J^\text{CPI}_\pi(\pi')$对$\pi$的显式依赖不能被忽略）。
\begin{align}
\nabla_\theta J^\text{CPI}_{\theta_\text{old}}(\theta)|_{\theta_\text{old}} &= \nabla_\theta\mathbb{E}_{\tau\sim\pi_{\theta_\text{old}}}\left[ \sum_{t\geq 0}A^{\pi_{\theta_\text{old}}}(s_t,a_t)\frac{\pi_{\theta}(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)} \right]|_{\theta_\text{old}} \label{eq:cpi-gradient-proof-1} \\
& = \mathbb{E}_{\tau\sim\pi_{\theta_\text{old}}}\left[ \sum_{t\geq 0}A^{\pi_{\theta_\text{old}}}(s_t,a_t)\frac{\nabla_\theta\pi_{\theta}(a_t|s_t)|_{\theta_\text{old}}}{\pi_{\theta_\text{old}}(a_t|s_t)} \right] \label{eq:cpi-gradient-proof-2} \\
& = \mathbb{E}_{\tau\sim\pi_{\theta_\text{old}}}\left[ \sum_{t\geq 0}A^{\pi_{\theta_\text{old}}}(s_t,a_t)\frac{\nabla_\theta\pi_{\theta}(a_t|s_t)|_{\theta_\text{old}}}{\pi_{\theta}(a_t|s_t)|_{\theta_\text{old}}} \right] \label{eq:cpi-gradient-proof-3} \\
& = \mathbb{E}_{\tau\sim\pi_{\theta_\text{old}}}\left[ \sum_{t\geq 0}A^{\pi_{\theta_\text{old}}}(s_t,a_t)\nabla_\theta\log\pi_{\theta}(a_t|s_t)|_{\theta_\text{old}} \right] \label{eq:cpi-gradient-proof-4} \\
& = \nabla_\theta J(\pi_\theta)|_{\theta_\text{old}} \label{eq:cpi-gradient-proof-5}
\end{align}
首先，在式\ref{eq:cpi}给出的代理目标上，使用旧策略的参数求导（梯度）。由于只有分数的分子包含变量$\theta$，我们可以将梯度和求值项移入，得到式\ref{eq:cpi-gradient-proof-2}。接着注意到，分母项 ${\pi_{\theta_\text{old}}}(a_t|s_t)$ 等价于在 $\theta=\theta_\text{old}$ 处对 $\pi_\theta$ 的取值，因此可按此重写，得到式\ref{eq:cpi-gradient-proof-3}。最后，回忆我们在推导策略梯度时使用的对数导数技巧：$\nabla_\theta\log p(x|\theta)=\frac{\nabla_\theta p(x|\theta)}{p(x|\theta)}$。借此我们可以重写该分式，得到式\ref{eq:cpi-gradient-proof-4}。这正是策略梯度$\nabla_\theta J(\pi_\theta)$。因此，我们得到式\ref{eq:cpi-gradient-1}。
\begin{equation}\label{eq:cpi-gradient-1}
\nabla_\theta J^{\text{CPI}}_{\theta_\text{old}}(\theta)|_{\theta_{\text{old}}} = \nabla_\theta J(\pi_\theta)|_{\theta_{\text{old}}}
\end{equation}
式\ref{eq:cpi-gradient-1}表明，代理目标的梯度等于策略梯度。这保证了在代理目标下进行的优化仍然是在执行策略梯度上升。这也很有用，因为现在可以直接度量策略改进，最大化该度量就意味着最大化策略改进。此外，我们还知道，在式\ref{eq:cpi}中，$J^\text{CPI}_\pi(\pi')$是对 $J(\pi')-J(\pi)$ 的线性近似，因为它们的一阶导数（梯度）相等。
}

在将 $J_\pi^\text{CPI}(\pi')$ 用作策略梯度算法的新目标之前，还有最后一个要求需要满足。$J_\pi^\text{CPI}(\pi')$ 只是对 $J(\pi')-J(\pi)$ 的近似，因此它会包含一定的误差。然而，当我们使用 $J_\pi^\text{CPI}(\pi')\approx J(\pi')-J(\pi)$ 时，希望能够保证 $J(\pi')-J(\pi)\geq 0$。因此，我们需要理解该近似所引入的误差。

如果相邻的策略 $\pi$ 与 $\pi'$ 在 KL 散度意义下足够接近，那么可以写出一个相对策略性能的界。为此，可将绝对误差表示为新目标 $J(\pi')$ 与其估计的改进 $J(\pi)+J_\pi^\text{CPI}(\pi')$ 之间的差值。随后，可以将该误差用 $\pi$ 与 $\pi'$ 的 KL 散度来加以界定。

\begin{equation}\label{eq:ppo-kl-divergence}
|\left( J(\pi')-J(\pi) \right)-J_\pi^\text{CPI}(\pi')|\leq{C\sqrt{\mathbb{E}_t[KL(\pi'(a_t|s_t)||\pi(a_t|s_t))]}}
\end{equation}

常数 $C$ 需要被选择，KL 表示 KL 散度。式\ref{eq:ppo-kl-divergence}表明，如果相邻策略 $\pi,\pi'$ 的分布彼此接近，使得右侧的 KL 散度较低，那么左侧的误差项也会较小。误差较小时，$J_\pi^\text{CPI}(\pi')$ 就是对 $J(\pi')-J(\pi)$ 的良好近似。

基于此，要推导我们想要的结果 $J(\pi')-J(\pi)\geq 0$ 相当直接。这被称为单调改进理论，因为它保证每次策略迭代至少是正的或零的改进，而不会出现退化。为得到该结论，首先展开式\ref{eq:ppo-kl-divergence}，并考虑其在式\ref{eq:lower-bound}中的下界。

\begin{equation}\label{eq:lower-bound}
J(\pi')-J(\pi)\geq J_\pi^\text{CPI}(\pi') - C\sqrt{\mathbb{E}_t[KL\left(\pi'(a_t|s_t)||\pi(a_t|s_t)\right)]}
\end{equation}

现在，让我们看看策略迭代某一步中的最坏情况。考虑对新策略 $\pi'$ 的所有选择，其中也包含旧策略 $\pi$（参数更新幅度为 0）。如果没有候选策略表现更好，就直接设定 $\pi'=\pi$，并在该次迭代中不进行更新。在这种情况下，式\ref{eq:cpi}告诉我们$J_\pi^\text{CPI}(\pi)=\mathbb{E}_{\tau\sim\pi}\left[\sum_{t\geq 0}A^\pi(a_t|s_t)\frac{\pi(a_t|s_t)}{\pi(a_t|s_t)}\right]=0$，因为一个策略相对于自身没有期望优势。根据恒等式，KL 散度满足 $KL(\pi||\pi)=0$。

为了接受策略的变更，式\ref{eq:lower-bound}表明，估计的策略改进 $J_\pi^\text{CPI}(\pi')$ 必须大于最大误差 $C\sqrt{\mathbb{E}_t[KL\left(\pi'(a_t|s_t)||\pi(a_t|s_t)\right)]}$。

如果将误差上界作为惩罚项加入到优化问题中，我们就能保证策略的单调改进。此时，我们的优化问题变为如下形式：

\begin{equation}\label{eq:optim-reform}
\begin{aligned}
\underset{\pi'}{\text{argmax}} & \left( J_\pi^\text{CPI}(\pi') - C\sqrt{\mathbb{E}_t[KL\left(\pi'(a_t|s_t)||\pi(a_t|s_t)\right)]} \right) \\
& \Rightarrow J(\pi')-J(\pi)\geq 0
\end{aligned}
\end{equation}

这一结果满足了我们的最终要求。它使我们能够避免在使用原始目标 $J(\pi)$ 时可能出现的性能崩溃。需要注意的一个关键区别是，单调改进并不保证收敛到最优策略 $\pi^*$。例如，策略优化仍可能停留在一个局部极大值处，在该处每次策略迭代都不产生改进——即$J(\pi')-J(\pi)=0$。保证收敛仍是一个困难的没有解决的问题。

最后一步是考虑如何在实践中实现式\ref{eq:optim-reform}提出的优化问题。一个思路是直接约束 KL 的期望，如式\ref{eq:kl-expectation}所示。

\begin{equation}\label{eq:kl-expectation}
\mathbb{E}_t[KL\left(\pi'(a_t|s_t)||\pi(a_t|s_t)\right)]\leq\delta
\end{equation}

$\delta$限制了 KL 散度的大小，因此实际上约束了新策略 $\pi'$ 相对旧策略 $\pi$ 能偏离的程度。只有策略空间中位于 $\pi$ 附近的小邻域内的候选策略才会被考虑。这个邻域称为置信域（trust region），而式\ref{eq:kl-expectation}称为置信域约束。需要注意的是，$\delta$是一个需要调参的超参数。

约束项 $\mathbb{E}_t[KL\left(\pi'(a_t|s_t)||\pi(a_t|s_t)\right)]$ 被写成对单个时间步 $t$ 的期望，因此将目标 $J_\pi^\text{CPI}(\pi')$ 也以这种形式书写是有帮助的，如式\ref{eq:cpi-single-step}所示。除此之外，由于我们将对 $\theta$ 最大化该目标，让我们也按照式\ref{eq:cpi-objective-simplify}将策略用 $\theta$ 表达。新策略写作 $\pi'=\pi_\theta$，而带有固定参数的旧策略写作 $\pi=\pi_{\theta_\text{old}}$。由旧策略计算的优势也可简记为 $A^\pi(s_t,a_t)=A^{\pi_{\theta_\text{old}}}_t$。

\begin{equation}\label{eq:cpi-single-step}
J_\pi^\text{CPI}(\pi') = \mathbb{E}_t\left[ \frac{\pi'(a_t|s_t)}{\pi(a_t|s_t)}A^\pi(s_t,a_t) \right]
\end{equation}

\begin{equation}\label{eq:cpi-objective-simplify}
J^\text{CPI}(\theta) = \mathbb{E}_t\left[ \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}A_t^{\pi_{\theta_\text{old}}} \right]
\end{equation}

将约束与代理目标合并后，置信域策略优化问题如式\ref{eq:trust-region-optim}所示。

\begin{equation}\label{eq:trust-region-optim}
\begin{aligned}
& \max_\theta\mathbb{E}_t\left[ \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}A_t^{\pi_{\theta_\text{old}}} \right] \\
& \text{需满足}\quad\mathbb{E}_t[KL\left(\pi_\theta(a_t|s_t)||\pi_{\theta_\text{old}}(a_t|s_t)\right)]\leq\delta
\end{aligned}
\end{equation}

总而言之，$J_\pi^\text{CPI}(\pi')$ 是对 $J(\pi')-J(\pi)$ 的线性近似，因为它的梯度等于策略梯度。它还在误差上界内保证单调改进。为在考虑潜在误差的同时确保改进，我们施加置信域约束以限制新旧策略之间的差异。只要策略变化保持在置信域内，我们就能避免性能崩溃。

已经提出了许多算法来解决置信域优化问题，其中包括自然策略梯度（NPG）、置信域策略优化（TRPO）和约束策略优化（CPO）。它们背后的理论相当复杂，算法实现也较为困难；其梯度计算成本较高，而且 $\delta$ 的取值难以确定。这些算法超出了本书的讨论范围，但它们的缺点正好激励我们引入下一种算法：近端策略优化（PPO）。

\section{近端策略优化（PPO）}

``近端策略优化算法''（PPO）由 Schulman 等人于 2017 年发表。PPO 易于实现、计算开销低，并且我们不需要选择 $\delta$。基于这些原因，它已成为最流行的策略梯度算法之一。

PPO 是一类通过简单而有效的启发式方法来解决带有信任域约束的策略优化问题的算法家族。它有两个变体：其一基于自适应 KL 惩罚，其二基于裁剪（clipped）目标。本节将介绍这两个变体。

在此之前，让我们先简化代理目标 $J^\text{CPI}(\theta)$，如式\ref{eq:cpi-rewrite-with-ratio}所示，将其写为 $p_t(\theta)=\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}$。为简洁起见，将优势 $A_t^{\pi_{\theta_\text{old}}}$ 记作 $A_t$，因为我们知道优势始终是用旧策略 $\pi_{\theta_\text{old}}$ 计算的。

\begin{equation}\label{eq:cpi-rewrite-with-ratio}
J^\text{CPI}(\theta) = \mathbb{E}_t\left[ \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}A_t^{\pi_{\theta_\text{old}}} \right] = \mathbb{E}_t\left[ p_t(\theta)A_t \right]
\end{equation}

PPO 的第一个变体称为带自适应 KL 惩罚的 PPO，其目标如式\ref{eq:ppo-klpen}所示。

它将 KL 约束 $\mathbb{E}_t[KL\left(\pi_\theta(a_t|s_t)||\pi_{\theta_\text{old}}(a_t|s_t)\right)]\leq\delta$ 转换为一个自适应的 KL 惩罚，并从重要性加权的优势中减去该惩罚。其结果的期望就是需要最大化的新目标。

\begin{equation}\label{eq:ppo-klpen}
J^{\text{KLPEN}}(\theta) = \max_\theta\mathbb{E}_t\left[ p_t(\theta)A_t - \beta KL\left(\pi_\theta(a_t|s_t)||\pi_{\theta_\text{old}}(a_t|s_t)\right) \right]
\end{equation}

式\ref{eq:ppo-klpen}被称为带KL惩罚的代理目标。$\beta$ 是一个自适应系数，用于控制 KL 惩罚的大小。它在控制优化的置信域方面与式\ref{eq:trust-region-optim}起到相同的作用。$\beta$ 越大，$\pi_\theta$ 与 $\pi_{\theta_\text{old}}$ 的差异越小。$\beta$ 越小，两种策略之间的容忍度越高。

使用常数系数的一个挑战在于，不同问题具有不同特性，因此很难找到一个在所有场景都适用的数值。即使在单一问题上，随着策略迭代，损失景观也会变化，因此先前有效的 $\beta$ 可能在后续不再有效——它需要随这些变化进行自适应。

为解决该问题，PPO 论文提出了一个基于启发式的 $\beta$ 更新规则，使其能够随时间自适应。$\beta$ 在每次策略更新后都会被更新，其新值在下一次迭代中使用。$\beta$ 的更新规则见算法\ref{algo:ppo-klpen}。它可以作为本节稍后将介绍的 PPO 算法中的一个子程序来使用。

\begin{algorithm}
\caption{带自适应KL惩罚的PPO}\label{algo:ppo-klpen}
\begin{algorithmic}[1]
\State 设置KL散度的期望的目标值$\delta_\text{tar}$
\State 将$\beta$初始化为一个随机值
\State 使用多轮小批次SGD来优化（最大化）KL惩罚替代目标
$$
J^{\text{KLPEN}}(\theta) = \mathbb{E}_t\left[ p_t(\theta)A_t - \beta KL\left(\pi_\theta(a_t|s_t)||\pi_{\theta_\text{old}}(a_t|s_t)\right) \right]
$$
\State 计算 $\delta=\mathbb{E}_t\left[ KL\left(\pi_\theta(a_t|s_t)||\pi_{\theta_\text{old}}(a_t|s_t)\right) \right]$
\If{$\delta<\delta_\text{tar}/1.5$}
\State $\beta\leftarrow\beta/2$
\ElsIf{$\delta>\delta_\text{tar}\times 1.5$}
\State $\beta\leftarrow\beta\times 2$
\Else
\State pass
\EndIf
\end{algorithmic}
\end{algorithm}

在每次迭代结束时，我们会估计$\delta$，并将其与目标值 $\delta_\text{tar}$ 比较。如果 $\delta$ 比 $\delta_\text{tar}$ 低出一定幅度，就通过减小 $\beta$ 来降低 KL 惩罚；相反，如果 $\delta$ 比 $\delta_\text{tar}$ 高出一定幅度，则通过增大 $\beta$ 来提高 KL 惩罚。用于确定幅度阈值和 $\beta$ 的更新规则的具体数值是通过经验选择的。作者分别选择了 1.5 和 2，但也发现算法对这些取值并不敏感。

还观察到，KL 散度有时会显著偏离其目标值 $\delta_\text{tar}$，但 $\beta$ 会快速调整。$\delta_\text{tar}$ 的良好取值也需要通过经验确定。

这种方法的优点是实现简单。然而，它并没有解决如何选择目标 $\delta$ 的问题。此外，由于需要计算 KL，它在计算上可能开销较大。

基于裁剪代理目标的 PPO 通过去除 KL 约束，并对式\ref{eq:cpi-objective-simplify}中的代理目标作更简单的修改来弥补这一点，如式\ref{eq:ppo-clip-objective}所示。

\begin{equation}\label{eq:ppo-clip-objective}
J^{\text{CLIP}}(\theta) = \mathbb{E}_t\left[ \min\left( p_t(\theta)A_t, \text{clip}\left( p_t(\theta), 1-\epsilon, 1+\epsilon \right)A_t \right) \right]
\end{equation}

式\ref{eq:ppo-clip-objective}被称为裁剪代理目标。$\epsilon$是定义裁剪邻域$|p_t(\theta)-1|\leq\epsilon$的数值。它是一个需要调参的超参数，且可在训练过程中衰减。$\min(\cdot)$内的第一项就是代理目标$J^\text{CPI}$。第二项 $\text{clip}\left( p_t(\theta)A_t, 1-\epsilon, 1+\epsilon \right)$ 将 $J^\text{CPI}$ 的取值限制在 $(1-\epsilon)A_t$ 与 $(1+\epsilon)A_t$ 之间。当 $p_t(\theta)$ 位于区间 $[1-\epsilon,1+\epsilon]$ 内时，$\min(\cdot)$ 中的两项相等。

该目标能够防止那些可能导致策略 $\pi_\theta$ 发生大幅且高风险变化的参数更新。为了量化策略变化的幅度，我们使用概率比率 $p_t(\theta)$。当新策略等于旧策略时，$p_t(\theta)=p_t(\theta_\text{old})=\frac{\pi_{\theta_\text{old}}(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}=1$。如果新策略偏离旧策略，$p_t(\theta)$ 就会偏离$1$。

核心思想是将 $p_t(\theta)$ 限制在 $\epsilon$ 邻域 $[1-\epsilon,1+\epsilon]$ 内。通常，在没有约束的情况下最大化代理目标 $J^\text{CPI}$ 可能会鼓励较大的策略更新。这是因为提升目标函数性能的一个机制是通过对 $p_t(\theta)$ 进行较大的改变。通过对目标进行裁剪，我们去除了那些会使 $p_t(\theta)$ 偏离该邻域的``大步更新''的激励。为说明原因，考虑 $p_t(\theta)A_t$ 取较大正值的情形，即要么 $A_t>0$ 且 $p_t(\theta)>0$，要么 $A_t<0$ 且 $p_t(\theta)<0$。

当 $A_t>0$ 且 $p_t(\theta)>0$ 时，如果 $p_t(\theta)$ 变得远大于 $1$，上限裁剪项 $1+\epsilon$ 会起作用，将 $p_t(\theta)$ 进行上界限制为 $p_t(\theta)\leq 1+\epsilon$，因此有 $J^{\text{CLIP}}\leq(1+\epsilon)A_t$。另一方面，当 $A_t<0$ 且 $p_t(\theta)<0$ 时，如果 $p_t(\theta)$ 变得远小于 $1$，下限裁剪项 $1-\epsilon$ 会起作用，同样给出上界 $J^{\text{CLIP}}\leq(1-\epsilon)A_t$。在式\ref{eq:ppo-clip-objective}取最小值时，$J^\text{CLIP}$ 总是以上述两种方式之一被上界限制。此外，取最小值还意味着 $J^\text{CLIP}$ 是原始代理目标 $J^\text{CPI}$ 的保守下界。这样，当 $p_t(\theta)$ 试图通过超过 $\epsilon A_t$ 的幅度来提升目标时，其影响会被忽略；但当它使目标变差时，其影响总会被计入。

由于目标函数 $J^\text{CLIP}$ 受到上界限制，$p_t(\theta)$ 没有动力偏离邻域 $[1-\epsilon,1+\epsilon]$ 去进行大幅度的策略更新。因此，策略更新是安全的。

此外，由于该目标假设样本是由 $\pi_{\theta_\text{old}}$ 生成的——也就是说，目标除了通过重要性权重外不依赖当前策略$\pi_\theta$——我们也可以合理地重复使用一条采样轨迹来进行多次参数更新。这提高了算法的样本效率。需要注意的是，目标依赖的 $\pi_{\theta_\text{old}}$ 会在每次训练步骤后更新。这意味着 PPO 是一种 on-policy 算法，因此旧的轨迹必须在一次训练步骤后被丢弃。

裁剪后的目标 $J^\text{CLIP}$ 计算成本低、易于理解，实现时只需对原始代理目标 $J^\text{CPI}$ 做少量、简单的修改。

计算开销最大的是概率比率 $p_t(\theta)$ 和优势函数 $A_t$。然而，这些是任何优化代理目标的算法所需的最小计算。其他操作是裁剪和取最小值，它们基本是常数时间的。

在 PPO 论文中，裁剪代理目标的变体优于带 KL 惩罚的变体。由于它更简单且表现更好，PPO 的裁剪变体更受青睐。

本章关于对策略梯度施加约束的讨论到此结束。我们从 REINFORCE 与 Actor-Critic 使用的策略梯度目标 $J(\theta)=\mathbb{E}_t\left[ A_t\log\pi_\theta(a_t|s_t) \right]$ 出发，引入了具有单调改进承诺的代理目标 $J^\text{CPI}(\theta)$，该承诺在我们约束相邻策略差异时成立。PPO 提供了两种约束代理目标的方法——使用 KL 惩罚或裁剪启发式，分别得到 $J^\text{KLPEN}$ 和 $J^\text{CLIP}$。让我们把这些策略梯度目标汇总到一起进行比较。

\begin{align}
J(\theta) & = \mathbb{E}_t\left[ A_t^{\pi_\theta}\log\pi_\theta(a_t|s_t) \right] & \textit{原始目标} \\
J^{\text{CPI}}(\theta) & = \mathbb{E}_t\left[ p_t(\theta)A_t^{\pi_\theta} \right] & \textit{替代目标} \\
J^{\text{CPI}}(\theta) \quad & \text{需满足}\quad \mathbb{E}_t\left[ KL(\pi_\theta||\pi_{\theta_\text{old}}) \right]\leq\delta & \textit{约束替代目标} \\
J^{\text{KLPEN}}(\theta) & = \mathbb{E}_t\left[ p_t(\theta)A^{\pi_{\theta_\text{old}}}_t - \beta KL(\pi_\theta||\pi_{\theta_\text{old}}) \right] & \textit{带自适应KL惩罚的PPO} \\
J^{\text{CLIP}}(\theta) & = \mathbb{E}_t\left[ \min\left( p_t(\theta)A_t, \text{clip}\left( p_t(\theta), 1-\epsilon, 1+\epsilon \right)A_t \right) \right] & \textit{带裁剪的PPO}
\end{align}

为清晰起见，我们将方程完全用 $\theta$ 来表示，以明确哪些策略是变量、哪些策略用于计算优势。请注意，只有原始目标使用当前策略 $\pi_\theta$ 来计算优势 $A_t^{\pi_\theta}$，而其余目标都使用旧策略来计算优势 $A_t^{\pi_{\theta_\text{old}}}$。

\chapter{组相对策略优化}

\section{算法理论}

\begin{marker}
GRPO：Group Relative Policy Optimization，组相对策略优化
\end{marker}

\begin{theorem}{GRPO的目标函数}{}
\begin{equation}
J^{\text{GRPO}}(\theta)=\frac{1}{G}\displaystyle\sum_{i=1}^G \frac{1}{|\tau_{i}|}\displaystyle\sum_{t=1}^{|\tau_{i}|}\min\left[ \frac{\pi_{\theta}(a_{\tau_{i,t}}|s_{\tau_{i,t}})}{\pi_{\theta_{\text{old}}}(a_{\tau_{i,t}}|s_{\tau_{i,t}})}A_{i,t},\text{clip}\left( \frac{\pi_{\theta}(a_{\tau_{i,t}}|s_{\tau_{i,t}})}{\pi_{\theta_{\text{old}}}(a_{\tau_{i,t}}|s_{\tau_{i,t}})},1-\epsilon,1+\epsilon \right)A_{i,t}  \right]-\beta D_{\text{KL}}\left[ \pi_{\theta}||\pi_{\text{ref}} \right]
\end{equation}
\end{theorem}

先来说明一下GRPO目标函数中每个数学符号的含义：

\begin{itemize}
    \item $\pi_\theta$表示正在更新的策略。
    \item $\pi_{\theta_\text{old}}$表示上一轮的策略，也就是旧策略。
    \item $\pi_\text{ref}$表示冻结的参考模型。
    \item $G$表示使用旧策略$\pi_{\theta_\text{old}}$采样的一组轨迹的轨迹数量，如果我们使用旧策略采样了10条轨迹，那么$G=10$。
    \item $\tau_i$表示第$i$条轨迹，$|\tau_i|$表示第$i$条轨迹的动作数量，也就是这条轨迹执行了多少个动作轨迹结束了。
    \item $\pi_{\theta}(a_{\tau_{i,t}}|s_{\tau_{i,t}})$表示第$i$轨迹的第$t$个时刻的状态为$s_{\tau_{i,t}}$，以及在这个状态下正在更新的策略$\pi_\theta$采取动作$a_{\tau_{i,t}}$的概率。
    \item $\pi_{\theta_{\text{old}}}(a_{\tau_{i,t}}|s_{\tau_{i,t}})$表示第$i$轨迹的第$t$个时刻的状态为$s_{\tau_{i,t}}$，以及在这个状态下旧策略$\pi_{\theta_\text{old}}$采取动作$a_{\tau_{i,t}}$的概率。
    \item $A_{i,t}$表示第$i$条轨迹的第$t$个时刻的动作的优势。
    \item $\beta D_\text{KL}[\pi_\theta|\pi_\text{ref}]$表示$\pi_\theta$和$\pi_\text{ref}$的偏离程度，也就是KL散度。$\beta$是超参数。
\end{itemize}

将采样一条轨迹封装为一个函数

\begin{codebox}{python}{采样一条轨迹的函数}
class Agent:
    ...

    def collect_trajectory(self, env):
        state = env.reset()
        states, log_probs, chosen_actions = [], [], []
        episode_reward = 0
        done = False

        while not done:
            # β$s_{\tau_{i,t}}$β
            states.append(state)
            # β$a_{\tau_{i,t}},\pi_{\theta_\text{old}}(a_{\tau_{i,t}}|s_{\tau_{i,t}})$β
            action, prob = self.get_action(state)
            # β$\log\pi_{\theta_\text{old}}(a_{\tau_{i,t}}|s_{\tau_{i,t}})$β
            log_prob = torch.log(prob[action])
            log_probs.append(log_prob.item())
            chosen_actions.append(action)
            # β$s_{\tau_{i,t+1}},R_{\tau_{i,t}}$β
            next_state, reward, done, _ = env.step(action)
            state = next_state
            episode_reward += reward
        # 归一化奖励
        normalized_reward = episode_reward / 200.0

        return states, log_probs, chosen_actions, normalized_reward
\end{codebox}

这里的归一化奖励需要说一下，我们已经知道木杆坚持200步不倒下，游戏就成功结束了。那么如果木杆坚持了3步就倒下，这条轨迹的奖励应该如何计算呢？这里我们选择$\frac{3}{200}=0.015$。这就是我们给这条轨迹的奖励。

GRPO的优势计算是和PPO的优势计算有区别的地方。PPO使用了价值函数网络评估每个动作的价值，并且使用了广义优势估计（GAE）。而GRPO创造性的提出了组相对优势。

也就是轨迹$\tau_i$相对于\textbf{组内}其它轨迹的优势是多少？也就是如下

轨迹$\tau_i$的归一化奖励是：

\begin{equation}
R_{\tau_{i}}^\text{normalized} = \frac{G(\tau_i)}{200}
\end{equation}

而一组轨迹的平均奖励是

\begin{equation}
\text{reward}_\text{mean} = \frac{1}{G}\sum_{i=0}^{G}R_{\tau_{i}}^\text{normalized}
\end{equation}

那么轨迹$\tau_i$相对于组内其它轨迹的优势为：

\begin{equation}
A_{\tau_i} = \frac{R_{\tau_{i}}^\text{normalized} - \text{reward}_\text{mean}}{\text{reward}_\text{std}}
\end{equation}

\begin{codebox}{python}{计算优势}
def calc_advantages_with_grpo(trajectories):
    # 每一条轨迹的归一化奖励组成的数组
    rewards = [r for o, l, a, r in trajectories]
    # 一组轨迹的归一化奖励的均值
    mean_reward = sum(rewards) / len(rewards)
    # 一组轨迹的归一化奖励的方差
    std_reward = np.std(rewards)  + 1e-8
    # β$[A_{\tau_0},A_{\tau_0},\dots,A_{\tau_G}]$β
    advantages = [(r - mean_reward) / std_reward for r in rewards]  
    
    return advantages
\end{codebox}

使用GRPO算法更新策略的代码如下

\begin{codebox}{python}{GRPO更新}
class Agent:
    ...

    def update(self, trajectories, n_iterations=20, eps=0.2):
        """使用旧策略采样的一组轨迹更新策略"""
        # 计算一组轨迹中每条轨迹的组内优势
        advantages = calc_advantages_with_grpo(trajectories)

        for i_iter in range(n_iterations):
            loss = 0
            # 遍历组内的每一条轨迹β$\tau_i$β和这条轨迹的组内优势
            for traj, advantage in zip(trajectories, advantages):
                # 取出轨迹$\tau_i$的状态、动作和动作的对数概率
                (states, log_probs, chosen_actions, _) = traj  
                trajectory_loss = 0

                for t in range(len(states)):
                    # 当前策略β$\pi_\theta$β在状态β$s_{\tau_{i,t}}$β下采取动作β$a_{\tau_{i,t}}$β
                    _, new_policy_probs = self.get_action(states[t])
                    # β$\log\pi_\theta(a_{\tau_{i,t}}|s_{\tau_{i,t}})$β
                    new_log_probs = torch.log(new_policy_probs)[chosen_actions[t]]
                    # log_probs[t]: β$\log\pi_{\theta_\text{old}}(a_{\tau_{i,t}}|s_{\tau_{i,t}})$β
                    # 计算在相同状态下，新旧策略采取同一个动作的概率的比值
                    ratio = torch.exp(new_log_probs - log_probs[t])
                    # 裁剪比值
                    clipped_ratio = torch.clamp(ratio, min=1 - eps, max=1 + eps)
                    # 取最小值
                    min = torch.min(ratio * advantage, clipped_ratio * advantage)
                    # 将损失累加到轨迹的损失中
                    trajectory_loss += -min
                # 归一化：轨迹的损失 = 每个动作的平均损失
                trajectory_loss /= len(states)
                # 将轨迹β$\tau_i$β的损失累加到一组的总损失上面
                loss += trajectory_loss
            # 归一化：一组轨迹的损失 = 每条轨迹的平均损失
            loss /= len(trajectories)
            # 更新网络
            self.optimizer.zero_grad()
            loss.backward()
            self.optimizer.step()

        return None
\end{codebox}

from transformers import AutoTokenizer, AutoModelForCausalLM, DataCollatorWithPadding
import torch
from torch import nn
import numpy as np
from torch.utils.data import DataLoader
from sklearn.metrics import confusion_matrix

model_name = 'gpt2-chinese-cluecorpussmall'
tokenizer = AutoTokenizer.from_pretrained(model_name)

tokenizer.eos_token = tokenizer.pad_token
REWARD_TOKEN_ID = tokenizer.eos_token_id

ds = load_dataset("csv", data_files="online_shopping_10_cats.csv")
ds_train = ds['train']

ds_train = ds_train.filter(lambda x : x['review'] != None and len(x['review']) > 20 and len(x['review']) < 1024)

def tokenize(batch):
    # 提取出文本内容
    outputs = tokenizer(batch['review'])
    # 每条数据一个评分，初始化为 0 。
    outputs['score'] = [0] * len(outputs['input_ids'])
    # 对每条数据的最后的reward token进行评分
    outputs['score_index'] = [0] * len(outputs['input_ids'])
    for i in range(len(outputs['input_ids'])):
        # 第 i 条数据的末尾添加一个 eos token，作为reward token
        outputs['input_ids'][i].append(REWARD_TOKEN_ID)
        # reward token的掩码设置为 1 。
        outputs['attention_mask'][i].append(1)
        # 正向情感的文本评分为 1 。负向情感的评分为 0 。
        outputs['score'][i] = float(batch['label'][i])
        # 对 reward token 进行评分，也就是评分的索引为 reward token 的索引。
        outputs['score_index'][i] = len(outputs['input_ids'][i]) - 1
    return outputs

map_kwargs = {
    "batched": True,
    "batch_size": 512,
    "remove_columns": ['cat', 'label', 'review']
}

class RewardHead(nn.Module):
    """奖励头，是一个线性层"""
    def __init__(self, config):
        super().__init__()
        # gpt2最后输出的隐藏层的维度
        self.hidden_size = config.hidden_size
        # 线性层用来对gpt2最后输出的隐藏层给奖励
        self.reward = nn.Linear(self.hidden_size, 1)
        self._post_init()

    def _post_init(self):
        # 使用正态分布初始化权重
        nn.init.normal_(
            self.reward.weight,
            std=(1.0 / np.sqrt(self.hidden_size + 1))
        )
        # 将偏置初始化为0
        nn.init.zeros_(self.reward.bias)

    def forward(self, hidden_states):
        # 给出奖励
        return self.reward(hidden_states)

class GPT2RewardHead(nn.Module):
    def __init__(self, model_name):
        super().__init__()
        self.llm = AutoModelForCausalLM.from_pretrained(model_name)
        self.reward_head = RewardHead(self.llm.config)

    def forward(self, input_ids, attention_mask):
        # gpt2的前向传播，但是还要输出隐藏层
        transformer_outputs = self.llm.forward(
            input_ids=input_ids,
            attention_mask=attention_mask,
            output_hidden_states=True
        )
        last_hidden_state = transformer_outputs.hidden_states[-1]
        # 给出奖励
        reward = self.reward_head(last_hidden_state).squeeze(-1)
        # sigmoid用来将奖励搞到(0,1)范围内
        return torch.sigmoid(reward)

        score = scores[batch_indices, inputs['score_index']]
